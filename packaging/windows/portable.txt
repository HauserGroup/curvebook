LumenCraft portable mode

While this file sits next to lumencraft.exe, LumenCraft keeps its preferences, color palette and
equation libraries, added fonts, crash-recovery files and logs in the LumenCraftData folder beside
it, and writes nothing to %APPDATA%. Copy the whole folder to move LumenCraft with its settings.

Delete this file to use the standard per-user settings folder (%APPDATA%\LumenCraft) instead.
