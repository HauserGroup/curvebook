# Extending LumenCraft

Follow the existing seams below whenever adding a capability. Every user-facing action must preserve **headless-first parity** (accessible via `lumencraft-engine`, CLI, MCP, and GUI where applicable) and satisfy [AGENTS.md](../AGENTS.md) and [docs/pitfalls.md](pitfalls.md).

## Extension Matrix ("You want to add -> Where -> How")

| You want to add | Where | How |
| :--- | :--- | :--- |
| **Engine command** (`CommandSpec`) | `crates/engine/src/cmd/{project,edit,sheet,table,info,analysis,graph,layout,export}.rs` (per-area `specs()` slices), assembled by `build_registry()` / `cmd::registry()` in `crates/engine/src/cmd/mod.rs` | Name the ID per [docs/command-ids.md](command-ids.md) (`<area>.<camelCaseAction>`). Add one `CommandSpec` to the owning area's `specs()` slice with its `CommandGroup`, accurate `Effects` bitflags (e.g. `MUTATES_DOCUMENT`, `WRITES_FILESYSTEM`, `MAY_DISCARD_DATA`, `IDEMPOTENT`; read-only commands carry no mutating flag, see `Effects::read_only_hint`), `input_schema`, `enabled` predicate, and typed `run` handler (parameters parsed via `serde_path_to_error`). Never rename shipped IDs. Add sweep/unit tests (`crates/engine/tests/command_sweep_props.rs`, `crates/engine/tests/registry_and_errors.rs`) and run `cargo xtask commands` / `cargo xtask commands --check`. |
| **UI command** (`UiCommandSpec`) | `crates/ui-egui/src/menus/ui_commands.rs` (`UI_COMMANDS`) + `crates/ui-egui/` menu/panel wiring + generated `crates/mcp/src/ui_catalog.rs` | Choose a `ui.*` (or `app.*`) ID per [docs/command-ids.md](command-ids.md). Add a `UiCommandSpec` entry using its named fields (`id`, `label`, `shortcut`, `params_doc`, `summary`, `beginner`). Wire its UI handler in `crates/ui-egui`. Run `cargo xtask ui-commands` so `crates/mcp/src/ui_catalog.rs` regenerates cleanly, then verify `cargo xtask ui-commands --check`. |
| **Cursor** | `crates/tools/src/cursors.toml`, `crates/tools/src/lib.rs` (`Cursor` enum), `UiApp::active_cursor` in `crates/ui-egui/src/lib.rs` | Add the `Cursor` variant in `crates/tools/src/lib.rs` and a matching `[[cursor]]` entry (`name`, `hotspot`, `when`) in `crates/tools/src/cursors.toml`; select it from `UiApp::active_cursor`. Record any new cursor image files in [ASSETS.md](../ASSETS.md) and run `cargo xtask cursors` + `cargo xtask assets`. |
| **Statistical / Scientific `AnalysisKind`** | `crates/doc/src/analysis.rs` (`AnalysisKind` & typed spec/result structs), `crates/stats` / `crates/fit` / `crates/transform`, `crates/engine`, `crates/ui-egui` | 1. Define typed parameter & result structs + `AnalysisKind` variant in `crates/doc/src/analysis.rs` (handling serde compatibility).<br>2. Implement pure-Rust math in `crates/stats` / `crates/transform` / `crates/fit` with peer-reviewed citations, edge-case coverage, and `D1` oracle checks (NIST StRD / verified reference values).<br>3. Wire execution/recalculation into `lumencraft-engine` (`analyze.run` / typed runner).<br>4. Expose parameters & results views in `crates/ui-egui`, CLI, and MCP. |
| **Curve-fit `ParametricModel`** | `crates/fit/src/library/{pharma,curves,nist}.rs` (resolved via `get_builtin_model` / `list_builtin_equations` in `crates/fit/src/library/mod.rs`) | Implement `ParametricModel` (`id`, `name`, `category`, `param_names`, `eval`, optional analytical `grad`, deterministic `initial_guess`, optional `default_bounds` / `derived_transforms`) with peer-reviewed textbook reference in doc comments. Register it by adding its ID to the category's `*_EQUATION_IDS` list and resolver (`resolve_pharma_model` / `resolve_curve_model` / `resolve_nist_model`), add NIST StRD / `D1` validation tests (including bad/degenerate initial inputs returning typed `Err`, never panics). |
| **`Importer` / `Exporter` format** | `crates/format/src/registry.rs` (`Importer` / `Exporter` traits, `FormatDescriptor`, `FormatRegistry::default_registry()`), parser modules such as `crates/format/src/{pzfx,prism,csv,export}.rs`; consumers `apps/lumencraft-cli/src/cmd_convert.rs`, `apps/lumencraft/src/desktop_host.rs`, `crates/mcp/src/formats.rs` | Implement `Importer` / `Exporter` cleanly (no panics or unchecked indexing on adversarial/malformed inputs; document format assumptions neutrally in clean-room terms) with a `FormatDescriptor` (`id`, `label`, `extensions`, `kind`). Register it in `FormatRegistry::default_registry()` so CLI, desktop host, and MCP pick it up. Use `lumencraft-platform` atomic writes for file outputs. Add round-trip and malformed-input tests (see `crates/format/tests/versioned_and_seams.rs`). |
| **Locale / UI string** | `crates/ui-egui/src/i18n.rs` | Add the key in `crates/ui-egui/src/i18n.rs` and provide translations across all active locale tables without duplicating existing keys. Run `cargo xtask i18n-report` (runs the `untranslated_report` test in `lumencraft-ui-egui`) to list untranslated keys, and `cargo test -p lumencraft-ui-egui`. |
| **Persisted-file version / migration** | `crates/format/src/versioned.rs` (`VersionStep`, `upgrade`, `PREFERENCES_MIGRATION_STEPS`), `crates/format/src/archive.rs` (`MIGRATION_STEPS`), config loaders in `apps/lumencraft/src/main.rs` | Bump the format version constant (`CURRENT_SCHEMA_VERSION`, `CURRENT_PREFERENCES_VERSION`, or the envelope's `format_version`), add a deterministic forward `VersionStep` migration to the matching steps slice (a compile-time assert ties slice length to the version), verify that reading a newer unsupported version fails safely without overwriting disk state ([docs/file-formats.md](file-formats.md)), add checked-in golden fixture tests, and regenerate schemas with `cargo xtask schemas` (`--check` in CI). |
| **Asset (icon, image, SVG, sample)** | Asset directory (never `.ttf`/`.otf`/`.woff`/`.woff2`!) + [ASSETS.md](../ASSETS.md) + [ATTRIBUTION.md](../ATTRIBUTION.md) | Verify the asset licence matches [docs/licences.md](licences.md). Add the file (never commit binary font files). Add a metadata row to [ASSETS.md](../ASSETS.md) and third-party credit to [ATTRIBUTION.md](../ATTRIBUTION.md) if applicable. Run `cargo xtask assets` (and `cargo xtask ico` if Windows icon sources changed). |
