>
> **How to read this checklist (revised 2026-11-15).** Earlier revisions ticked `[x]` when a `UiApp` state machine existed and the semantic `gui_only` agent harness (`dispatch_gui_action`, `ui.inspect`, `ui.invoke_menu` with structured params, `ui.answer_dialog` field patches) could drive it. A human-GUI audit found that most of those surfaces are not drawn as interactive widgets in the desktop window or web canvas. From this revision:
>
> - `[x]` means **a person can operate it in the rendered GUI** (desktop, and web where noted) using pointer and keyboard.
> - `[ ]` means it is not human-operable yet. Each line states whether the **state machine / agent harness** exists and which `R10` item makes it human-operable.
>
> **Architecture note:** `lumencraft-ui-egui` (`L6`) holds the pure-Rust `UiApp` state shell and a deterministic CPU RGBA/PNG compositor (`render_workspace_rgba`). The native app (`apps/lumencraft`, `eframe`/`egui`/`wgpu` + `rfd`) draws a real `egui` menu bar and presents the compositor buffer as one texture below it; the web app (`apps/lumencraft-web`) blits the same buffer to a WebGL2 canvas with no menu bar. Chrome text uses an uppercase-only 5×7 ASCII bitmap font. Interactive widgets are planned in [`R10.1`](ROADMAP.md#r101-interactive-chrome-architecture-decision--spike). Test counts and live metrics are in [`STATUS.md`](STATUS.md).

## Risk Spike `S1` Decision (Spreadsheet Grid at 60 fps): **GO**

- **Decision:** **GO** — virtualized two-tier spreadsheet engine (`lumencraft-tools::GridToolState`) + sparse window formatter (`lumencraft-ui-egui::GridViewState`). No redesign required.
- **Measured Evidence (`1,000 × 1,000 = 1,000,000 cells`):**
  - `lumencraft-tools` (`spike_s1_grid_perf`, dev `opt-level=1`, `120` frames): `min = 0.0340 ms`, `p50 = 0.0390 ms`, `p95 = 0.0432 ms`, `max = 0.0612 ms`, `mean = 0.0392 ms`; `1,000,000`-row tail jump `elapsed = 0.0150 ms` (`62` visible cells).
  - `lumencraft-ui-egui` (`grid_perf_s1`): `SPIKE_S1_UI_1M` grouped scroll (`120` frames) -> `p50 = 0.061 ms`, `p95 = 0.507 ms`, `mean = 0.245 ms`, `max = 7.795 ms` (`37 × 14` visible cells); `Select All (1,000,000 cells)` + batched `table.excludeCells` -> `0.044 ms` (`intents = 1`, `quick_stats` capped at `50,000` cells); `multivar 30 frames` -> `mean = 0.069 ms`, `max = 1.246 ms`.
  - Paste (`ImportPasteWizardState`) and `table.excludeCells` round-trips dispatch cleanly through `Engine` commands well inside the `16.67 ms` 60-fps frame budget.
- **Scope note:** `S1` measures the state/formatting layer. The rendered grid does not yet scroll by wheel or keyboard past the visible viewport (`R10.8`).
