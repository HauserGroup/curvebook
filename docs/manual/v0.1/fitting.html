Curve Fitting & Nonlinear Regression Reference

This reference documents CurveBook's parametric linear and nonlinear regression algorithms, residual weighting schemes, global parameter sharing and constant constraints, profile-likelihood uncertainty, R13.1 diagnostic safeguards, model comparison, unknown interpolation, custom equation DSL, and adaptive ODE solver. For the full compiled catalog of built-in equations, parameters, and solver defaults, see the Parametric Equations Registry. For sheet-level analysis execution and table compatibility, see Statistical Analyses (#analysis-nonlinear-regression), Linear Regression (#analysis-linear-regression), and the Command Reference.

Fitting Methods & Estimation Objectives

Nonlinear regression fits a parametric model y = f(x; θ) + ε over active (non-excluded) observations via analyze.run, fit.run, or analysis.add (nonlinear / AnalysisKind::NonlinearRegression). Observations may come from raw replicates or pre-summarized XY subcolumns (MeanSdN, MeanSemN, MeanCvN), and can be filtered by predictor interval using x_range_filter.

Note

Under weighted least squares, PoissonDeviance, or replicate-moment weighting, weighted_ss is the objective minimized by the optimizer, while reported rss and unweighted R2= 1 - rss/ TSS remain expressed in original response Y units (Motulsky & Christopoulos 2004).

1. Least Squares (method: "least_squares")

Minimizes the weighted sum of squared residuals:

SSw(θ) = w1(y1- ŷ1)2+ w2(y2- ŷ2)2+ ... + wN(yN- ŷN)2
  • Core optimizer: Trust-region Levenberg–Marquardt (Levenberg 1944; Marquardt 1963; Moré 1978 / MINPACK-1 lmder) using column-scaled QR decomposition on the augmented Jacobian [J; √λD], quadratic trust-region step updates (ρ ≥ 10-4 acceptance, contraction in [0.1, 0.5], expansion up to max(δ, 2 |D p|)), and active-face projection onto box constraints.
  • Tolerances & budgets: Relative residual reduction ftol = 1e-15, parameter step xtol = 1e-14, projected gradient cosine gtol = 1e-13 (and stall check stall_gtol = 1e-4), default max_iters = 1000 (HARD_MAX_ITERS = 50000).
  • Warm start & rescue: Before or during difficult starts, when use_simplex_warm_start is active (default true), bounded Nelder–Mead simplex optimization (Nelder & Mead 1965; Lagarias et al. 1998) locates an initial basin or rescues non-finite / stalled starts.
  • Jacobians: Built-in models supply analytical derivatives df / dθj where available; models without analytical gradients (including all custom DSL equations) use central finite differences h = 10-6· max(|θj|, 1), switching to interior one-sided differences h = 1.5 × 10-8· max(|θj|, 1) at an active bound (Nocedal & Wright 2006).

2. Poisson Deviance (method: "poisson_deviance")

For non-negative integer or count data yi≥ 0 with strictly positive predicted mean μ̂i= f(xi; θ) > 0, minimizes exact Poisson log-likelihood deviance (McCullagh & Nelder 1989):

D(θ) = 2 · [ y1ln(y1/ μ̂1) - (y1- μ̂1) ] + ... + 2 · [ yNln(yN/ μ̂N) - (yN- μ̂N) ]

where terms with yi= 0 contribute 2 μ̂i smoothly via deviance_bd0.

  • Solver: Iteratively reweighted least squares (IRLS; Green 1984) assigning working weights 1 / μ̂i around inner trust-region Levenberg–Marquardt updates until relative deviance change drops below 10-10.
  • Domain guards: Negative observed counts (yi< 0) raise FitError::ImpossibleWeights, and custom Gaussian weighting choices are ignored in favor of exact Poisson variance V(μ) = μ.
  • Inference: Dispersion is fixed at φ = 1, using asymptotic Fisher information covariance, normal two-sided z quantiles for curve bands, and exact Poisson log-likelihood AICc and BIC.

3. Robust Cauchy Regression (method: "robust_cauchy")

Outlier-resistant Lorentzian M-estimator minimizing the logarithmic loss (Motulsky & Brown 2006):

L(θ) = ln(1 + (r1/ RSDR)2) + ... + ln(1 + (rN/ RSDR)2)

solved by Cauchy IRLS around the Robust Standard Deviation of Residuals (RSDR), defined from the 68.27th percentile of weighted residual magnitudes scaled by √N / (N - Kfree). Points remain in the dataset without binary deletion.

Important

Under robust_cauchy, parametric standard errors, confidence intervals, parameter dependency, Hougaard skewness, residual SD (Sy.x), AICc, BIC, studentized residuals, replicate lack-of-fit tests, and confidence/prediction bands are intentionally suppressed (InferenceAvailability::NotApplicableInRobustMode — empty cells / Open CIs), because standard Gaussian linearization covariance is invalid under non-quadratic Cauchy loss. Best-fit parameters, unweighted R2, and RSDR remain reported. Use rout_outlier_elimination when parametric inference on clean inliers is required.

4. ROUT Outlier Elimination (method: "rout_outlier_elimination")

Implements the three-stage ROUT procedure of Motulsky & Brown (2006):

  1. Robust Cauchy fit: Fit the model with robust_cauchy to locate a resistant baseline and compute RSDR on base-weighted residuals rw,i= √wi(yi- ŷi), ensuring heteroscedastic weighting schemes (such as relative_square 1/Y2) map residuals onto a uniform scale before testing.
  2. FDR screening over extreme tail: Evaluate two-sided Student-t P values against RSDR (ti= |rw,i| / RSDR) and apply Benjamini–Hochberg (1995) step-up FDR control only across the top 30% of observations furthest from the curve (start = floor(0.70 * N)). The remaining lower ≈ 70% of residuals are never tested (q_value = 1.0, is_outlier = false).
  3. Least-squares refit: Re-optimize retained non-outlier points using ordinary or weighted least squares, seeded from the robust Cauchy parameters.
  • Parameter constraint: fdr_q_percent is specified in percentage points (default 1.0 for Q = 1%) and must satisfy 0 < Q ≤ 50 in nonlinear regression (compare univariate column outlier detection, which allows (0, 100]).
  • Empty/insufficient inliers: If ROUT excludes too many points to retain residual degrees of freedom, the solver returns FitError::InsufficientData or surfaces a non-converged warning; excluded outlier coordinates and q-values are tabulated in the diagnostics sheet without mutating the source DataSheet.

Weighting Schemes & Replicate Summary Moments

The weighting field (WeightingScheme) scales residual errors prior to least-squares and Cauchy/ROUT fitting (ignored by poisson_deviance; explicit cell-level weights, when attached, take precedence over the global scheme). See also Parametric Equations Registry: Weighting Schemes.

Canonical KeyFormulaTypical Error Model & Guard
nonewi= 1Homoscedastic uniform absolute SD across Y
relative_squarewi= 1 / Yi2Constant relative %CV scatter; undefined if any Yi= 0
relativewi= 1 / |Yi|Poisson-like variance proportional to mean response; undefined if any Yi= 0
general_power_ywi= 1 / |Yi|kPower variance via finite weighting_power (k); undefined if Yi= 0 when k > 0
inverse_xwi= 1 / |Xi|Scatter proportional to √|X|; undefined if any Xi= 0
inverse_x2wi= 1 / Xi2Relative predictor-magnitude scatter; undefined if any Xi= 0
observed_sdwi= 1 / SDi2Pre-summarized empirical variance; requires SDi> 0 at every active row

Any non-finite, zero-denominator, or overflowing weight produces FitError::ImpossibleWeights.

Replicate Summary Subcolumns (MeanSdN, MeanSemN, MeanCvN)

When the source XY table uses a pre-summarized subcolumn mode (MeanSdN, MeanSemN, MeanCvN) and weighting is none (or on pre-summarized inputs without explicit weights and not using observed_sd), the solver reconstructs exact replicate-sufficient statistics from (mean_i, sd_i, n_i):

  • Each row's weighted residual scales by √wi· ni.
  • Total sample size sums N = n1+ ... + nM.
  • Pooled within-row replicate variance contributes wi(ni- 1) SDi2 into total weighted_ss and unweighted rss, matching an equivalent raw-replicate fit identically for least-squares estimates, parameter SEs, AICc, and replicate lack-of-fit tests (Motulsky & Christopoulos 2004).

Under observed_sd, each pre-summarized row contributes one summary point weighted by 1 / SDi2 (requiring finite SDi> 0).

Parameter Scopes, Bounds & Dynamic Hooks

Each entry in parameter_rules (ParameterRule) targets a case-insensitive model parameter name (ParametricModel::param_names) and controls initial guess, box constraints, sharing across datasets, or constant fixation (ParameterScope).

Canonical scopeBehavior & Free Parameters Consumed

  • Initial guesses (initial_override) & bounds (lower_bound, upper_bound): When initial_override is omitted, deterministic model heuristics compute dataset-aware initial guesses (or pooled guesses for shared_global). Box bounds must be finite with lower≤ upper and are intersected with intrinsic domain bounds (e.g., positive rate constants). Setting lower= upper converts a free slot into a fixed constant consuming 0 free parameters.
  • Default model rules: Certain models supply default_parameter_rules when no user rule overrides them—for example, centered polynomials fix XCenter to the active predictor sample mean x̄ to preserve Jacobian conditioning.

Parameter Uncertainty, Diagnostics & R13.1 Safeguards

Profile-Likelihood & Wald Confidence Intervals

  • Wald asymptotic covariance: Cov(θ̂) = sw2(JTJ)-1 where sw2= SSw/ df (df= N - Kfree) for least squares, or Cov(θ̂) = (JTW J)-1 (W = diag(μ̂i)) for Poisson deviance. Symmetric Wald intervals use Student tdf, α/2 (least squares) or normal zα/2 (Poisson).
  • Venzon–Moolgavkar (1988) profile-likelihood intervals (profile_likelihood_ci: true, default): For each free parameter θj, nuisance parameters θ-j are re-optimized via reduced trust-region LM (run_reduced_lm_with_domain, tolerance ftol = 1e-12, xtol = 1e-12) across an outward bracket scan refined by Brent root finding (rel_tol = 1e-7) to solve:
SSprof(θj) = SSmin· (1 + 1dfF1 - α(1, df))

(or deviance increase Δ D(θj) = χ21, 1 - α in poisson_deviance). If the profiled objective fails to reach the critical threshold before hitting a boundary, search horizon, or flat plateau, the endpoint reports CiBound::Open (open / unbounded), alerting users without truncating to symmetric Wald approximations (Bates & Watts 1988; Seber & Wild 1989).

Hougaard Skewness (g1)

When 1 ≤ Kfree≤ 10, df> 0, and the fit is identifiable, compute_hougaard evaluates Hougaard's (1985) third-order skewness measure g1 per parameter from central second-derivative tensor approximations:

  • |g1| < 0.1: effectively linear behavior (Wald and profile CIs agree closely).
  • 0.1 ≤ |g1| < 0.25: mild parameter-effects nonlinearity.
  • 0.25 ≤ |g1| ≤ 1.0: substantial skewness; asymmetric profile-likelihood intervals are materially more accurate than symmetric intervals.
  • |g1| > 1.0: extreme nonlinearity; triggers a diagnostic checklist entry (QOL-7, remediation: None).

Collinearity & Fit Identifiability (identify_unstable_parameters)

Variance-inflation collinearity per free parameter is reported via Bates & Watts dependency:

Rj2= 1 - 1(JTJ)jj· [(JTJ)-1]jj
  • Dependency > 0.99: emits a collinearity warning on the parameter and checklist.
  • FitIdentifiability::Ambiguous (FitStatus::Ambiguous, ParameterNote::Unstable, checklist metric "Dependency > 0.9999 or rank-deficient Jacobian"): raised when rank-revealing QR detects numerical rank deficiency, Rj2> 0.9999 (MAX_DEPENDENCY = 1 - 1 / 10000), or profile-likelihood intervals return CiBound::Open on unidentifiable asymptotes/EC50 plateaus (for instance, sparse dose-response curves lacking upper/lower concentration coverage per Sebaugh 2011).

Residual Diagnostics, Range Filters & Threshold Alerts

  • Inclusive predictor filter (x_range_filter): Restricts fit observations to active rows satisfying X ∈ [xmin, xmax] (unbounded on omitted sides) while optionally evaluating curve overlays over an independent [plot_x_min, plot_x_max] display range. Counts points excluded by the range filter cleanly.
  • Unweighted R2 alert (flag_r_squared_below): Optional threshold in [0, 1] emitting an R squared below threshold diagnostic checklist entry (ChecklistStatus::Warn, remediation: None) whenever unweighted R2 drops below threshold.
  • Internally studentized residuals: ei= rw,i/ (sw√1 - hii) using tangent-plane leverage hii= Ji(JTJ)-1JiT (Cook & Weisberg 1982) when identifiable and Kfree≤ 64.
  • Replicates lack-of-fit test: Partitions residual variance/deviance across exact replicate predictor groups into Pure Error and Lack of Fit, returning an F-statistic and P value (honoring weighting, Poisson deviance, and replicate summary moments).
  • Runs test: Wald–Wolfowitz runs test sorted along ascending X, combined across datasets in global fits.
  • Normality & homoscedasticity battery: Shapiro–Wilk (falling back to D'Agostino–Pearson K2 outside SW range), Anderson–Darling, and Lilliefors Kolmogorov–Smirnov on weighted/Pearson residuals, plus Spearman rank correlation of |rw,i| vs ŷi (n ≥ 4).
  • Confidence & prediction bands + AUC: Delta-method mean confidence bands and observation prediction bands sampled over curve_overlay_segments (256 by default; Graphs Reference), plus fitted-curve vs empirical trapezoidal Area Under the Curve (fit_auc).

Note

Following QOL-7, every assumption checklist item emitted by CurveBook sets remediation: None and reports purely objective metrics and limitations without recommending alternative models or transformations (Quality of Life Capabilities).

Model Comparison & Unknown Interpolation

Comparing Models (comparison)

  1. Nested Extra-Sum-of-Squares F-test (extra_sum_of_squares_f / shared_parameter_comparison): Compares a simpler constrained/null model (alternative_equation_id or globally shared parameters via SharedGlobal) against the fuller model (df1> df2):
F = (SSnull- SSalt) / (dfnull- dfalt)SSalt/ dfalt

Under poisson_deviance or likelihood_ratio_test, performs an asymptotic deviance difference χ2 Likelihood Ratio Test (comparing Δ D against χ2Δ df). Emits a ModelComparison tab with F / χ2, df, P value, preferred model label, and percentage difference in residual SD.

  1. Corrected Akaike Information Criterion (aicc): Evaluates small-sample corrected AIC for identical active observations and weights (Burnham & Anderson 2002):
AICc= N ln(SSwN) + 2 (K + 1) + 2 (K + 1)(K + 2)N - K - 2

(using -2 lnL + 2K + 2K(K+1)N - K - 1 under exact Poisson log-likelihood lnL, where K excludes fixed constants), alongside Δ AICc, normalized Akaike weights walt, wnull, and evidence ratio. Unavailable (None) in robust_cauchy mode.

Forward Prediction & Inverse Interpolation (interpolate_unknowns)

When interpolate_unknowns is enabled, unpaired (X, blank) rows are predicted forward (Ŷ) and (blank, Y) rows are inverted numerically (X̂) along each fitted dataset's curve via bracketed Brent + damped Newton root search:

  • Confidence intervals & modes (Mean vs Replicates): Delta-method curve uncertainty σmean2(x) = g(x)TCov(θ̂) g(x) (where g(x) is the parameter gradient of f(x; θ̂)) yields the curve-mean band (Interpolated Mean X when Y represents an observed single/averaged mean), while adding observation scatter σpred2(x) = σmean2(x) + sw2/ w(x) yields single-replicate inverse prediction intervals (Interpolated Replicates) whenever active data include replicate scatter (sw> 0). Forward and inverse intervals propagate SEs via SE(X̂) = σ / |df / dX| evaluated at X̂.
  • Extrapolation & non-finite guards: Any inverse or forward row with predictor outside [Xmin, Xmax] or target Y outside the curve's monotonic image sets an explicit Extrapolated warning flag (or Empty when no real root exists, e.g., Y beyond a 4PL asymptote).

Custom Equation DSL & First-Order ODE Models

User-defined nonlinear models compile through CompiledDslModel::compile (custom_dsl) into a stack-based sandboxed bytecode VM implementing ParametricModel. Custom models use central finite-difference Jacobians and support explicit equations, dataset-branch selectors, implicit roots, initial-value rules, derived transforms, and first-order ODEs.

Grammar, Sections & Precedence

Equations are newline-delimited statements organized into optional [Equation] (default), [InitialValues], and [Transforms] sections. Line comments start with ;, //, or #.

Operator precedence (highest to lowest):

  1. Parentheses (...), numeric literals, variable/parameter identifiers, and function calls f(...)
  2. Exponentiation ^ or ** (right-associative; binds tighter than prefix unary operators, so -X^2 parses as -(X^2) while X^-2 parses as X^(-2))
  3. Prefix unary +, -, ! (NOT)
  4. Multiplicative *, /, % (left-associative)
  5. Additive +, - (left-associative)
  6. Comparisons ==, =, !=, <>, <, <=, >, >=
  7. Logical && (AND), then || (OR)

Statement forms:

  • Explicit assignment: Y = Bottom + (Top - Bottom) / (1 + 10^((LogEC50 - X) * HillSlope)) (or a bare expression rhs).
  • Local helper variables: span = Top - Bottom prior to the target Y = ... line.
  • Conditional piecewise branching: IF(cond, then_expr, else_expr).
  • Dataset-specific lines (<A>, <B>, <A:C>, <2>): Prefix lines with angle-bracket column letters (A..Z.. or 1-based dataset indices) or ranges to apply distinct expressions or parameter assignments across datasets in a shared fit. Unscoped free identifiers become optimizable parameters; dataset-scoped assignments restrict parameters cleanly.
  • Initial-value rules ([InitialValues]): Supply deterministic starting formulas using built-in summary tokens calculated from active (X, Y) points: YMIN, YMAX, XMIN, XMAX, XATYMIN, XATYMAX, XMID, YMEAN, YMEDIAN, XMEAN, XMEDIAN, YAT0, SLOPE, etc.
  • Derived scalar transforms ([Transforms]): Post-fit algebraic expressions (e.g., EC50 = 10^LogEC50) evaluated at converged estimates and emitted into derived_scalars and summary tabs.
  • Built-in constants & predictors: Predictor X (or T for ODE time axis; multi-predictor X0, X1, ...), dependent response Y, mathematical constants PI, E, LN2, LN10, LOG10E, LOG2E, SQRT2, PHI.

Implicit Equations (LHS = RHS)

Any [Equation] target with Y appearing on both sides (or an algebraic equation where LHS is not plain Y) compiles as an implicit root problem F(X, Y; θ) = LHS- RHS= 0:

  • Scans multi-decade, scale-augmented positive and negative probe grids outward from 0 to bracket a sign change, then refines via safeguarded Brent root finding (rel_tol = 1e-13, with [0, root] tight re-bracketing near zero).
  • Falls back to damped Newton iteration when no sign-change bracket is found. Returns None (domain failure) if residual |F| > tol or non-finite.

First-Order ODE Models (dY/dX / dY/dT / D(Y, X))

Single-equation first-order ODEs specify a derivative line (dY/dX = -k * Y, dY/dT = r * Y * (1 - Y / K), or D(Y, X) = ...) paired with an initial condition (Y(0) = Y0 or Y(t0) = expr, defaulting to t0= 0 if Y0 = ... is given):

  • Integrator: Adaptive embedded 5(4) Dormand–Prince RK45 (Dormand & Prince 1980) with mixed step-error control err≤ atol· yref+ rtol· max(|y|, |ynew|) (rtol = 1e-8, Hairer, Nørsett & Wanner 1993 §II.4), supporting both forward (tend> t0) and backward (tend< t0) sweeps.
  • Trajectory reuse cache: Observations are sorted per dataset along ascending X, allowing continuous trajectory frontier advancement and reuse (MAX_CACHED_ODE_TRAJECTORIES = 4, MAX_CACHED_ODE_KNOTS = 4,096) across curve points and overlays.
