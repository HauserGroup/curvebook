Graphing, Annotation & Page Layout Capabilities

See Graphs & Page Layouts for full engine command and workflow guidance across the features below:

  • Composite XY, series nudging & spaghetti trajectories: Mix ScatterAndLine and BarWithReplicates series on Xy graphs, shift series via SeriesOffsetSpec (x_data, x_pt, y_pt), trace longitudinal IndividualReplicateTrajectories, or set show_raw_data: false for decoupled subset-fit curve overlays.
  • Horizontal orientation & population pyramids: Set CartesianOrientation::Horizontal on Column and Grouped plots paired with TickLabelFormat::AbsoluteDecimal (|x|) for symmetric diverging pyramids.
  • Kaplan–Meier modes & Greenwood intervals: Select SurvivalDisplayMetric (PercentSurvival, PercentCumulativeEvent, FractionSurvival), toggle staircase vs. direct segments, and choose Greenwood Sem or ConfidenceInterval95 error displays.
  • Forest study bounds & vertical-label heatmaps: Plot Forest study confidence intervals with optional pooled summary diamonds (forest_show_pooled_diamond), and configure HeatmapLabelSpec row/column label sources, Horizontal0 / Angled45 / Vertical90 column rotation, cell annotations, and cell_gap_pt.
  • Batch per-dataset creation & selective style cloning: Create one graph sheet per dataset in one undo step (one_per_data_set on graph.create), and selectively clone palette, frame/axes, or error-bar/legend settings via graph.applyStyleFrom.
  • Live rectangular tables, TeX equations & embedded raster images: Place transposable row/column slices via EmbeddedResultTable and LiveTable (selected_rows, selected_cols, EmbeddedTableStyle), live ModelEquation TeX boxes, and content-addressed EmbeddedImage assets (graph.insertImage, layout.insertImage, edit.pasteImage).
  • Page Layout scale equalization, Z-order & inset layers: Equalize inner plot scaling across panels with layout.equalizeScaling (MatchSmallest, MatchLargest, ExplicitPercent), adjust panel depth with layout.reorderPanel, and layer transparent axis-free inset graphs.
