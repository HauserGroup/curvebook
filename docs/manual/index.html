CurveBook Reference Manual

Documentation & user guides

Released versions of the generated static HTML reference manual are published under docs/manual/v<major>.<minor>/ when a release snapshot is cut, and this entry page redirects automatically to the latest published version.

Note

Until a frozen snapshot is published for the Beta release tag, open the source Markdown guides directly on GitHub below or build the full static manual locally from a repository checkout:

cargo xtask docs-site
