CurveBook Reference Manual

Versioned documentation snapshots

Released versions of the static HTML reference manual are published under docs/manual/v<major>.<minor>/ when a release tag is cut, and this entry page redirects automatically to the latest release.

Pre-release status: No frozen release snapshot has been published on this branch yet. Build and preview the full static manual locally from a checkout of the repository:

cargo xtask docs-site

Source documentation on GitHub

While the first Beta release snapshot is in preparation, source Markdown guides and JSON Schemas remain readable directly in the repository:

  • MCP setup for beginners — configure an AI assistant to drive CurveBook.
  • MCP server reference — transports, dynamic toolsets, and strict --gui-only mode.
  • CLI reference (curvebook-cli) — subcommands, flags, and exit codes.
  • Control protocol & batch format — loopback --control JSON-lines and curvebook.batch.v1.
  • Engine command catalog — generated command IDs, schemas, and effects.
  • JSON Schemas — project, preferences, archive manifest, and batch schemas.
  • Contributor & development guide — building, testing, and clean-room rules.
