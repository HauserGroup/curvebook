Quick facts & answers.

CurveBook is a free, open-source (MIT OR Apache-2.0) biostatistics, nonlinear regression, and scientific graphing application written in pure Rust. It runs offline with zero telemetry on macOS, Windows, Linux, and FreeBSD.

Answers

Frequently asked questions

Is CurveBook free and open source?

Yes, CurveBook is completely free and open-source software dual-licensed under MIT OR Apache-2.0, with no account, license key, or subscription required. You can use it for academic, personal, or commercial research, inspect the Rust source code on GitHub, and redistribute or modify it under either license.

Can I open a .pzfx or .prism file on Linux, macOS, or Windows?

Yes, CurveBook reads the data tables inside .pzfx (XML) and .prism (ZIP archive) files offline on Linux, macOS, Windows, and FreeBSD, and exports them to CSV, TSV, or a .curvebook project. CurveBook imports the data tables, replicate and summary subcolumns, titles, excluded-value markers, and info notes; graphs, analysis results, and layouts are not imported and can be rerun in CurveBook. See the .pzfx and .prism import guide and the files reference for details.

Does CurveBook work offline? Does it collect telemetry?

CurveBook works completely offline and collects zero telemetry, zero analytics, and zero crash reports. It makes no outbound network calls and includes no auto-updater, enforced by automated repository checks (cargo xtask telemetry). Full per-platform local storage details are documented in the Privacy Policy and Privacy & Security Reference.

Which operating systems does CurveBook support?

CurveBook provides native Beta packages for macOS (signed and notarized universal arm64 + x86_64 .dmg), Windows (x64 and arm64 .msi, currently unsigned in Beta), Linux (x86_64 and aarch64 .AppImage), and FreeBSD (x86_64 preview .tar.gz). Every release bundle includes both the desktop GUI and curvebook-cli, paired with SHA256SUMS.txt and GitHub Sigstore build provenance attestations; see the Get Started Guide.

What statistical analyses and nonlinear curve-fitting methods does CurveBook include?

CurveBook includes descriptive statistics, parametric and nonparametric group comparisons (t-tests, Mann-Whitney, Wilcoxon, Kruskal-Wallis, Friedman), one-way, multi-way, repeated-measures, and REML mixed-effects ANOVA with multiple-comparison post tests and Compact Letter Display, contingency and ROC analysis, Kaplan-Meier and Cox proportional hazards survival modeling, generalized linear models, PCA, clustering, power and sample-size planning, and weighted nonlinear regression. Nonlinear regression supports parametric equations, custom DSL formulas, ODE models, profile-likelihood confidence intervals, ROUT outlier handling, and AICc or extra sum-of-squares F model comparison; browse the analyses reference and curve-fitting guide.

How do I share a CurveBook project with a collaborator?

Send a single .curvebook project archive, an unpacked .curvebook.d/ directory for Git version control, or a reusable .cbtemplate file so your collaborator can reopen the full workspace in CurveBook. All data tables, formulas, statistical results, graphs, page layouts, and notes travel together in one deterministic project; note that this is manual file sharing rather than hosted live collaboration, and externally linked CSV or TSV paths keep provenance metadata without automatically bundling external files.

Can AI assistants use CurveBook?

Yes, CurveBook ships with a built-in local stdio Model Context Protocol (MCP) server (curvebook-cli mcp) that lets AI assistants create tables, run analyses, fit curves, and export publication figures directly into .curvebook files. The MCP server opens no network sockets, supports --workdir <dir> filesystem confinement and optional live desktop attachment via --control-port, and produces standard projects you can inspect interactively in the desktop app. See the Beginner's MCP Guide and MCP Automation Reference.

How is CurveBook developed?

CurveBook is an independent open-source project written from scratch in safe Rust using clean-room engineering based on published, peer-reviewed statistical and numerical literature. No commercial statistical or graphing software is used to develop CurveBook, and no proprietary code or assets are copied; automated checks (cargo xtask cleanroom and cargo xtask brands) enforce these boundaries on every change.
