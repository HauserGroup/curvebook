Answers

Frequently asked questions

Is CurveBook free and open source?

Yes. CurveBook is free, open-source software dual-licensed under MIT OR Apache-2.0. It requires no account, license key, or subscription. You can use it for academic, personal, or commercial research, inspect the source code on GitHub, and share or adapt it under either license.

Can I open or export .pzfx and .prism files on Linux, macOS, or Windows?

Yes. CurveBook opens data tables, exclusions, rich text, and info sheets from XML .pzfx and .prism files offline on macOS, Windows, Linux, and FreeBSD. Legacy binary .pzf files (including binary PCFF files named .pzfx) are not supported; re-save them as XML .pzfx or .prism first. Stored .prism results open as read-only snapshots, with graph previews when available. For export, .pzfx export saves your data tables and info sheets only. Analyses, graphs and layouts stay in your .curvebook project. Written to match the .pzfx structure of real files; not tested in other applications. Beta does not ship .prism export because real archives depend on undocumented binary and digest entries. See the .pzfx and .prism guide, the format specification, and the files reference.

Does CurveBook work offline? Does it collect telemetry?

Yes. CurveBook works completely offline with zero telemetry, analytics, or crash reports. It makes no network calls and has no auto-updater, verified by automated checks on every change. See the Privacy Policy and privacy & security reference for local storage details.

Which operating systems does CurveBook support?

Beta releases include native installers for macOS (signed universal .dmg), Windows (unsigned x64 and ARM64 .msi), and Linux (x86_64 and ARM64 .AppImage). FreeBSD x86_64 ships as a CLI-only .tar.gz archive. Every desktop installer bundles both the desktop app and curvebook-cli, with checksums and build attestations. See the get started guide for install and verification steps.

What statistical analyses and nonlinear curve-fitting methods does CurveBook include?

CurveBook includes descriptive statistics, t-tests, nonparametric tests, and ordinary, repeated-measures, and mixed-effects ANOVA with multiple comparisons. It also supports contingency tables, ROC curves, Kaplan–Meier and Cox survival models, GLMs, PCA, clustering, and power planning. Nonlinear regression offers built-in equations, custom formulas, outlier detection, confidence intervals, and model comparison. Browse the analyses reference and curve-fitting reference.

How do I share or merge CurveBook projects?

Share a single .curvebook file, a Git-friendly .curvebook.d/ folder, or a reusable .cbtemplate template. Data tables, formulas, results, graphs, layouts, and notes all travel together. Choose File › Merge Project… to copy sheets from another .curvebook, .pzfx, .prism, or .xlsx file with removable origin badges.

Can AI assistants use CurveBook?

Yes. CurveBook includes a local Model Context Protocol (MCP) server (curvebook-cli mcp). Your AI assistant can build tables, run analyses, fit curves, and export graphs directly into standard .curvebook files. Everything stays offline and restricted to the folder you pick, and you can inspect every project in the desktop app. See the beginner's MCP guide and MCP reference.

How is CurveBook developed?

CurveBook is an independent open-source project built from scratch in Rust from published scientific literature. No commercial statistical software is used in development, and no proprietary code or assets are copied. Automated repository checks enforce these clean-room boundaries on every change. See our clean-room policy.

How do I cite CurveBook in a paper?

Include the exact CurveBook version you ran. You can copy it from Help › Cite CurveBook, About CurveBook, the result Methods panel, or curvebook-cli --version. Ready-to-paste plain-text and BibTeX references are in How to cite CurveBook and CITATION.cff.
