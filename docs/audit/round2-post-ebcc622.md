## Executive Summary & Systemic Themes

Across the `29` feature, runtime, packaging, and CI governance commits landed after `ebcc622`, Round 2 identified **`138` new defects** (`38` `S1`, `67` `S2`, `31` `S3`, `2` `S4`):

1. **Silent wrong statistical, pharmacological, transform, and chart results (`S1` cluster in `S02`, `S03`, `S04`, `S07`, `S08`, `S10`):**
   - **Statistics & Power (`S02`):** Factorial/RM ANOVA post-hoc multiplicity uses wrong means/error strata and adjusts per-slice (`R2-S02-01`); Cohen's kappa SE omits the Fleiss–Cohen–Everitt squared expectation term (`R2-S02-02`); `power.rs` pairs Welch's unpooled SE with Student's pooled `df`, leaves `allocation_ratio` stale when `sample_size_group2` is supplied, rejects `k < 1.0`, and skips `target_power <= alpha` checks on one-sided solvers (`R2-S02-03`..`R2-S02-05`, `R2-S02-11`); XY trapezoidal AUC integrates arbitrary replicate rows on tied `X` (`R2-S02-06`); row-wise MV descriptive stats average numeric `Label` IDs into row means (`R2-S02-07`); and overflow/loop hazards panic or hang in `paired_sign_test`, `ExactBinomial`, and `power.rs` (`R2-S02-08`..`R2-S02-10`).
   - **Curve Fitting & Equation Rendering (`S03`, `S08`, `S09`):** `OneSiteCompetitionLigandDepletion` omits nonspecific bound radioligand `NS * FreeHot` (`R2-S03-01`); `tex_format.rs` suffers unbounded recursion stack overflow on nested DSL input (`R2-S03-02`), contradicts `curves.rs` formulas on 4 built-in models (`R2-S03-05`), and interacts with `parse_equation_segments` (`in_math: false`, `R2-S09-03`); fitted-curve AUC silently truncates or projects multi-predictor MV fits onto `x[0]` (`R2-S03-03`, `R2-S03-04`); and `ModelEquation` chart boxes fabricate `1.0`/`0.0` coefficients or substitute `R2`/`RSS` into polynomial terms (`R2-S08-01`), while `Superimposed` before-after connectors swap column values (`R2-S08-02`).
   - **Table Reshaping, Randomization & Engine Dispatch (`S04`, `S07`, `S10`):** `SimulatedDistribution::Binomial` suffers catastrophic cancellation and `f64` integer precision loss above `2^53` (`R2-S04-01`); archetype conversions ignore `Cell::excluded` on MV factors, propagate a single group's excluded `X` across all groups, misclassify numeric row factors as `Continuous`, and mark lossy pre-summarized conversions as `lossy = false` (`R2-S04-02`..`R2-S04-05`); `project::recalculate_with_links` duplicates `linked_regions` ($4^k$ explosion) and re-appends linked rows (`R2-S07-02`); `methods_report` fabricates uncomputed effect sizes and wrong formulas (`R2-S07-03`); `stats.run` / `analysis.updateParams` silently drop Cox PH `tie_method` and `reference_levels` (`R2-S07-04`); `ui.inspect` dialog `widget_id`s are silently ignored by `_ => {}` in `apply_field_patch` (`R2-S10-02`); and `parse_f64_list` splits comma-decimal proportions into wrong Goodness-of-Fit *p*-values (`R2-S10-03`).
2. **`--gui-only` (`GuiOnlyPolicy::Strict`) & `WorkdirGuard` security boundary bypasses (`S01`, `S07`, `S10`, `S12`):**
   - `table.convertArchetype` collides with a read-only `table.convert` inspect alias (`R2-S07-01`), and `ui.invoke_menu` executes arbitrary registered engine/`UI_COMMANDS` mutations with caller-supplied `"params"` as `Caller::Ui` (`R2-S10-01`), defeating `GuiOnlyPolicy::Strict` (including arbitrary host reads/writes on `--control --gui-only`).
   - `--control-port` MCP attachment neither queries nor propagates `gui_only` on the remote desktop control server (`R2-S12-01`); `--control --gui-only` leaves `doc.inspect`, `app.quit`, `render.svg`, `render.pdf`, and state-mutating `ui.result.inspectDiagnostics` unguarded (`R2-S10-04`); MCP `open_file`/`save_file` probe unguarded `raw_path` on the host before `WorkdirGuard` runs (`R2-S12-04`); and `PATH_PARAM_KEYS` classifies bare `"template"` as a path, breaking `table.importPlateMap` (`R2-S01-02`).
3. **Unpacked `.lumencraft.d`, `.lctemplate`, and future-schema data-loss hazards (`S05`, `S06`, `S12`):**
   - `save_project_unpacked_dir` unlinks arbitrary files listed in untrusted `manifest.json` `csv_path` entries (such as `.git/HEAD` or `README.md`) and wipes unexpected files in `<dir>/sheets/` (`R2-S06-01`), while `FormatRegistry::exporter_for_path`, CLI `is_unpacked_project_path`, and `project.save` classify **any** existing directory (`path.is_dir()`, including `.`) as `.lumencraft.d` (`R2-S06-02`, `R2-S12-02`).
   - Project and template save paths never check for a newer on-disk `schema_version`, clobbering future-version `.lumencraft`, `.lumencraft.d`, and `.lctemplate` files (`R2-S06-03`), while `.lctemplate` stripping leaves `ProjectDocument::checkpoints` intact (`R2-S05-02`) and CLI `convert` falls back to `open_archive_bytes` on `.lctemplate` validation errors (`R2-S12-05`).
4. **Native `eframe` desktop & browser WASM/WebGL2 host lifecycle defects (`S11`):**
   - In the native `eframe` window (`9db2f2b`), closing a clean secondary session exits the single OS viewport and force-closes dirty background sessions without prompt (`R2-S11-01`); `Cmd+S`/`Ctrl+S` routes through `ShortcutRegistry` with `{}` params and succeeds without writing to disk (`R2-S11-02`); `Cmd+C`/`Ctrl+C` clobbers rich PDF/PNG/HTML clipboard flavors via trailing `ctx.copy_text` (`R2-S11-07`); normal close wipes `snapshot.lcproj` and skips shortcut persistence (`R2-S11-08`); and `--control` suppresses the GUI window (`R2-S11-09`).
   - In `lumencraft-web` (`3cd144d`, `461ad33`, `9b7b056`), `open_project_json_bytes` skips `migrate_document_json` and `validate_project_document` (`R2-S11-03`); closing a contending read-only tab forces the active lock-holding tab to drop its Web Lock (`R2-S11-04`); and `WebBridgeSession` swallows errors as `"[]"` without hydrating `window.localStorage` (`R2-S11-05`).
5. **CI, release workflow, and `xtask` governance blind spots (`S13`, `S11`):**
   - `release.yml`'s `licenses` job fails unconditionally on GitHub Actions (`CI=true`) due to uninstalled `cargo-about`/`cargo-deny` while the HTML fallback omits license texts (`R2-S13-01`); the `freebsd` job interpolates `${{ inputs.version }}` into shell (`R2-S13-02`); `publish` `--clobber`s already-published releases without checking `Cargo.toml` version parity (`R2-S13-03`); `ci.yml`/`release.yml` execute unpinned `curl | bash` (`actionlint` `main`/`latest`) and `@master` actions (`R2-S13-04`); `packaging/macos/verify.sh --require-notarized` skips CLI `.zip` Gatekeeper checks (`R2-S11-10`); and `xtask` static scanners (`telemetry`, `layers`, `secrets`, `licenses`, `workflows`) have bypassable string heuristics (`R2-S13-05`..`R2-S13-10`).
