### R2-S07-01 · S1 · `table.convertArchetype` alias collision bypasses `GuiOnlyPolicy::Strict` and skips undo/dirty/rollback

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c

- **Failure scenario:** Under `--gui-only` (`GuiOnlyPolicy::Strict`), an MCP, Control, or CLI caller invokes `table.convertArchetype` with `{"sheet_id": "data-1", "target_kind": "Column", "allow_lossy": true, "preview_only": false, "preview": true}`. `is_preview_only_convert(&params)` returns `true` (because `"preview"` is `true`), bypassing `is_strict_gui_only_allowed` (`crates/engine/src/lib.rs:715`) and taking the `read_only` fast path (`crates/engine/src/lib.rs:984`) without cloning `before = self.doc.clone()`. - **Evidence:**

- **Related:** `R2-S10-01`, `R2-S12-01`.

### R2-S07-02 · S1 · `project::recalculate_with_links` duplicates `linked_regions` ($4^k$ explosion) and re-appends linked data on every recalculation

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c

- **Category:** wrong-result
- **Defect:** `project::recalculate_with_links` re-runs `apply_import_link_pipeline` directly on each existing `LinkedRegion` twice per call without truncating the newly appended `LinkedRegion` metadata or normalizing `AppendRows`/`AppendColumns`/`InsertRows` placement modes to in-place `Overwrite`.
- **Failure scenario:** Create a live internal link via `table.pasteLink` (e.g., with `mode: "append_rows"` or `"overwrite"`), then run `project.recalculate` (or `info.setConstant`, `sheet.rename`, `sheet.delete`, `sheet.duplicateFamily`, or `sheet.unfreeze`, all of which call `project::recalculate_with_links`). - **Evidence:**
  ```rust

  ```
- **Suggested fix:** Deduplicate link refresh through `dag::recalculate_project` / `dag::refresh_single_region` (which snapshots `prior_len = target.linked_regions.len()`, normalizes refresh placement to `PlacementMode::Overwrite` at `region.target_range.start`, updates `target_range`, and truncates `linked_regions` back to `prior_len`).
- **Related:** `R1-S07-08`.
