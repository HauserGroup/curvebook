### R2-S08-01 · S1 · `ModelEquation` fabricates numerical coefficients or substitutes `R2`/`RSS` as polynomial parameters when dataset scalars are missing, global, or `Pending`

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c
- **Location:** `crates/chart/src/equation_box.rs:88-98` and `crates/chart/src/equation_box.rs:102-158` at that base (introduced in `f4b4c42`)
- **Category:** wrong-result
- **Defect:** `resolve_model_equation` ignores `ResultStatus::Pending`, omits an empty-parameter guard in `AnalysisKind::LinearRegression`, falls back to another dataset's `FittedCurveOverlay` when `data_set_index` was not fitted, and feeds global (`data_set_index: None`) summary metrics (`"R2"`, `"RSS"`, `"AUC (trapezoidal)"`) from `collect_dataset_scalars` into positional polynomial and unknown-model TeX formatters.
- **Failure scenario:**
  1. **Unfitted dataset or `Pending` linear regression (`crates/chart/src/equation_box.rs:107-110, 130-135`):** Unlike `PassingBablok` (`:138-140`), `LinearRegression` never checks `lin_params.is_empty() && substituted`. When `res.status == ResultStatus::Pending`, or when `data_set_index` on a multi-dataset `Xy` sheet was excluded from `data_sets_to_analyze` or had `< 2` valid pairs (`Completed`), `lin_params` is empty (`&[]`); `format_polynomial_equation_tex(1, through_origin, &[], true, 4)` (`crates/fit/src/tex_format.rs:140-153`) defaults missing `Slope` to `1.0` and `YIntercept` to `0.0`, silently rendering `Y = 1 \cdot X + 0` (or `Y = 1 \cdot X`) on the figure as if fitted.
  2. **Global `R2`/`RSS` consumed as regression coefficients (`crates/chart/src/equation_box.rs:88-96, 116-129, 145-153`):** `run_nonlinear_regression` (`crates/fit/src/result.rs:491-492`) emits global `("R2", None, fit.r_squared)` and `("RSS", None, fit.rss)`. When `ModelEquation` references an unanalyzed `data_set_index` on a sheet where another dataset was fitted with `"straight_line"`, `"line_through_origin"`, or `"polynomial_2"`..`"polynomial_6"`, `.or_else(|| res.fitted_curves.iter().find(...))` (`:121, :149`) borrows the other dataset's `equation_id` (even if `!c.converged`) while `collect_dataset_scalars` returns `[("R2", r2), ("RSS", rss)]`, which `format_polynomial_equation_tex` (`crates/fit/src/tex_format.rs:140-170`) consumes positionally (`params[0]`, `params[1]`) to render e.g. `Y = 0.995 + 14.2 \cdot X + 0 \cdot X^{2}`. Even on a single analyzed dataset, `format_unknown_fallback` (`crates/fit/src/tex_format.rs:214-230`) appends `R2` and `RSS` into `f(X; ...)` as model parameters.
- **Evidence:**
  ```rust
  AnalysisKind::NonlinearRegression(nl) => {
      let overlay = res
          .fitted_curves
          .iter()
          .find(|c| c.data_set_index == data_set_index && !c.equation_id.trim().is_empty())
          .or_else(|| res.fitted_curves.iter().find(|c| !c.equation_id.trim().is_empty()));
  ...
  AnalysisKind::LinearRegression(lin) => {
      let through_origin = lin.force_through_origin && !lin.deming_model_ii;
      let lin_params = collect_linear_params(&params, through_origin);
      let tex = format_polynomial_equation_tex(1, through_origin, &lin_params, substituted, EQUATION_SIG_FIGS);
      ResolvedEquation::Tex(tex)
  }
  ```
- **Suggested fix:** Return a placeholder when `matches!(res.status, ResultStatus::Pending)` or when `substituted` lacks converged parameters for the exact requested `data_set_index` (including `lin_params.is_empty()` in `LinearRegression` and `!overlay.converged` / missing `data_set_index` in `NonlinearRegression`). Do not fall back to another dataset's overlay or merge `data_set_index: None` goodness-of-fit scalars (`R2`, `RSS`, `Sy.x`, `AICc`, `AUC`) into model parameter lists when multi-dataset models emit dataset-scoped parameter scalars.
- **Related:** `R2-S03-09`, `R1-X2-01` (distinct: reproduces on `Completed` multi-dataset fits and fresh `Pending` sheets with no failed re-run).


- **Related:** none.
