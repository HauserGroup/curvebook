### R2-S02-01 · S1 · Factorial and repeated-measures ANOVA post-hoc multiplicity uses wrong means, wrong error strata, and per-slice-only adjustment

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c
- **Location:** `crates/stats/src/anova.rs:2166-2318` (with `ms_residual` populated at `crates/stats/src/anova.rs:1208-1216` and `crates/stats/src/anova.rs:2516-2521`) at that base (introduced in `916897a`)
- **Category:** wrong-result
- **Defect:** `run_factorial_multiplicity` and `run_simple_effects_for_pair` pool raw observations into one-way group bins against `result.ms_residual`, which uses the wrong error stratum and pseudoreplicated `n` for repeated-measures/REML designs, tests confounded crude means instead of unweighted marginal means in unbalanced factorials, and adjusts simple effects per slice rather than across the simple-effects family.
- **Failure scenario:**
  1. **Repeated-measures two-way & REML (`ColumnFactorMatched`, `RowFactorMatched`, `BothFactorsMatched`, or REML fallback):** `fit_rm_two_way_anova` sets `ms_residual = err_ab_ss / err_ab_df` (within-subject residual $\sigma_e^2$) and `run_rm_two_way_reml_fallback` sets `ms_residual = reml.sigma2_error`, omitting subject variance $\sigma_u^2$, while `bins[lvl]` counts all $s \cdot b$ observations as independent. In a split-plot `ColumnFactorMatched` study ($A = 2$ groups, $s = 5$ subjects/group, $B = 4$ repeated timepoints, $\sigma_u = 10$, $\sigma_e = 1$, mean difference $= 4$), true between-subject $t = 0.6317$ ($P = 0.5452$, $\text{df} = 8$), whereas `run_factorial_multiplicity` computes $t = 12.6491$ ($P = 4.17 \times 10^{-12}$, $\text{df} = 24$) — a $20.02\times$ SE underestimate.
  2. **Unbalanced factorial marginal comparisons:** On an unbalanced $2 \times 2$ design with zero Factor $A$ effect ($\mu_{A_1 B_1} = \mu_{A_2 B_1} = 10$, $\mu_{A_1 B_2} = \mu_{A_2 B_2} = 30$) and cell counts $n_{11} = 9, n_{12} = 1, n_{21} = 1, n_{22} = 9$, the Type III ANOVA table reports $F_A = 0$, $P = 1$, while `"Multiple comparisons: Factor A (marginal means)"` pools raw observations ($\bar{y}_{A_1} = 12$, $\bar{y}_{A_2} = 28$) and flags a spurious difference of $-16.0$ (and for `GamesHowell`/`TamhaneT2`/`DunnettT3`, `build_factorial_group_inputs` computes `sd` from pooled raw variance inflated by Factor $B$'s main effect).
  3. **Simple-effects multiplicity & index collisions:** `run_simple_effects_for_pair` calls `compare_groups_pairwise` inside each `cond_levels` loop iteration before `combined.extend(details)`. Whenever `target_factor` has 2 levels across $C \ge 2$ conditioning levels (e.g., Drug vs. Placebo across 4 timepoints), each slice has $m = 1$ pair so `adjusted_p_or_q == raw_p` (zero multiplicity correction across the $C$ tests), and all four tabs push colliding `0..k` `group_a`/`group_b` indices into `out.pairwise_comparisons`.
- **Evidence:**
  ```rust
  let inputs = build_factorial_group_inputs(target_levels, bins, result.ms_residual)?;
  if inputs.len() < 2 {
      continue;
  }
  let eff_spec = effective_factorial_mult_spec(cfg.mult_spec, &inputs);
  let mut details = compare_groups_pairwise(&inputs, result.ms_residual, result.df_residual, &eff_spec)?;
  ```
  Oracle (`Rscript --vanilla`, R 4.5.2):
  `RM split-plot: t_true=0.6317 (p=0.5452, df=8) vs t_code=12.6491 (p=4.1678e-12, df=24), SE ratio=20.02x`
  `Unbalanced 2x2 zero-A-effect: LS_diff=0.0 vs crude_pooled_diff=-16.0`
- **Suggested fix:** Compute post-hoc contrasts from least-squares cell/marginal means and their model-based contrast covariance (using each term's stratum error MS/df in RM designs and `(X^T V^{-1} X)^{-1}` with Satterthwaite/Kenward–Roger df in REML), and apply family-wise/FDR adjustment across the full set of contrasts when `target_levels.len() == 2` across multiple conditioning slices.
- **Related:** none.

### R2-S02-02 · S1 · Cohen's kappa (unweighted & weighted) asymptotic SE omits squared expectation term, inflating SE and CIs by 1.8x–5.1x

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c
- **Location:** `crates/stats/src/categorical.rs:1464-1468` (newly wired into `run_contingency_analysis` at `crates/stats/src/categorical.rs:1570-1572` and `crates/stats/src/categorical.rs:1806-1854`) at that base (wired in `916897a`)
- **Category:** wrong-result
- **Defect:** `cohens_kappa` subtracts `(kappa * (1.0 - pe) - (po - pe)).powi(2)` — which is algebraically identically `0.0` because `kappa = (po - pe) / (1.0 - pe)` — instead of the Fleiss–Cohen–Everitt (1969) squared expectation `[po - 2 * pe * (1 - kappa)]^2`, and `916897a` newly wired `ContingencyMethod::CohenKappa` into `run_contingency_analysis`, shipping severely inflated SEs and CIs on every kappa sheet.
- **Failure scenario:** Running `ContingencyMethod::CohenKappa { weighting: Unweighted }` (or `Linear` / `Quadratic`) on a $2 \times 2$ agreement table `[[45, 5], [5, 45]]` ($N = 100$, $\kappa = 0.80$) reports `SE = 0.11136` and 95% CI `[0.5817, 1.0000]` in `"contingency-kappa"` and `ResultSheet.scalars`, whereas the true Fleiss–Cohen–Everitt asymptotic SE is `0.05980` with 95% CI `[0.6828, 0.9172]` ($1.86\times$ too wide; $5.15\times$ too wide at `[[96, 1], [1, 2]]`).
- **Evidence:**
  ```rust
  let c_const = po * pe - 2.0 * pe + po;
  let _ = c_const;
  let denom_sq = (1.0 - pe).powi(2).max(1e-18);
  let se = ((var_sum - (kappa * (1.0 - pe) - (po - pe)).powi(2)).max(0.0) / (nf * denom_sq)).sqrt();
  ```
  Oracle (`Rscript --vanilla`, R 4.5.2 + 200,000 multinomial draws):
  - `[[45, 5], [5, 45]]` (unweighted): `SE_true = 0.05980`, `SE_mc = 0.0597`, `SE_code = 0.11136` (`1.86x` inflation)
  - `[[40, 8, 2], [6, 30, 4], [1, 3, 26]]` (quadratic): `SE_true = 0.04970`, `SE_code = 0.15524` (`3.12x` inflation)
  - `[[96, 1], [1, 2]]` (unweighted): `SE_true = 0.18411`, `SE_code = 0.94890` (`5.15x` inflation)
- **Suggested fix:** Replace `(kappa * (1.0 - pe) - (po - pe)).powi(2)` with `(po - 2.0 * pe * (1.0 - kappa)).powi(2)` (which equals $\bigl(\sum_{i,j} p_{ij}[w_{ij} - (\bar{w}_{i\cdot} + \bar{w}_{\cdot j})(1 - \kappa)]\bigr)^2$).
- **Related:** none.

### R2-S02-03 · S1 · Heteroscedastic `TwoSampleUnpairedT` power engine pairs Welch's unpooled SE with Student's pooled degrees of freedom

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c
- **Location:** `crates/stats/src/power.rs:664-670` and `crates/stats/src/power.rs:1070-1078` at that base (introduced in `52e18d7`)
- **Category:** wrong-result
- **Defect:** When `sd_group2: Some(sd2)` with `sd2 != sd1`, `resolve_unpaired_t_effect` and `eval_power_at` compute Welch's unpooled noncentrality $\delta = \Delta / \sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}$ while evaluating the critical value and noncentral-$t$ tail at pooled $\text{df} = n_1 + n_2 - 2$ instead of Welch–Satterthwaite degrees of freedom (and mislabeling the result `"Unpaired Student t-test"` / `"Cohen's d"`).
- **Failure scenario:** For `TwoSampleUnpairedT` with `mean_diff = 10.0, sd = 10.0, sd_group2 = Some(1.0), sample_size = Some(5.0), allocation_ratio = 5.0` ($n_1 = 5, n_2 = 25, \alpha = 0.05$ two-sided), `solve_power` evaluates $\delta = 2.2316$ at $\text{df} = 28$ and reports `achieved_power = 0.5762`, whereas Welch–Satterthwaite has $\text{df} = 4.016$ and analytical/simulated Welch $t$-test power is `0.435` (~14 percentage points lower), causing `SampleSize` solves to under-size heteroscedastic studies.
- **Evidence:**
  ```rust
  let eff_sd = if let Some(sd2_raw) = sd_group2 {
      let sd2 = validate_positive_finite("sd_group2", *sd2_raw)?;
      ((k * sd1 * sd1 + sd2 * sd2) / (k + 1.0)).sqrt()
  } else {
      sd1
  };
  ...
  let n2 = n2_explicit.unwrap_or(ctx.allocation_ratio * n1);
  let df = n1 + n2 - 2.0;
  ...
  let delta = *d * ((n1 * n2) / (n1 + n2)).sqrt();
  t_power(df, delta, ctx.alpha, ctx.tail_mode, None)
  ```
  Oracle (`Rscript --vanilla`, R 4.5.2, 200,000 normal Monte Carlo trials of `t.test(..., var.equal = FALSE)` at $n_1=5, n_2=25, \sigma_1=10, \sigma_2=1, \Delta=10$): empirical Welch power `= 0.4339`, Satterthwaite NCT power `= 0.4352` ($\text{df} = 4.016$), `power.rs` output `= 0.5762` ($\text{df} = 28$).
- **Suggested fix:** Carry `(sd1, sd2)` in `ResolvedEffect::UnpairedT` when `sd_group2` is provided, compute $\delta = \Delta / \sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}$ and Welch–Satterthwaite $\text{df} = (\sigma_1^2/n_1 + \sigma_2^2/n_2)^2 / [(\sigma_1^2/n_1)^2/(n_1 - 1) + (\sigma_2^2/n_2)^2/(n_2 - 1)]$ at `(n1, n2)` in `eval_power_at`, and emit a Welch $t$-test convention note.
- **Related:** `R2-S02-04`.

### R2-S02-04 · S1 · Explicit `sample_size_group2` in `solve_power` leaves `allocation_ratio` stale, corrupting power, curves, and sensitivity tables

- **Evidence:**

- **Related:** `R2-S02-03`, `R2-S02-05`.

### R2-S02-05 · S1 · Unequal allocation `k < 1.0` aborts `solve_power` on two-sample families and ceiling rounding can under-deliver target power

- **Base:** fda1cc0106092834d97b53289ec2a99c1bf0439c
- **Location:** `crates/stats/src/power.rs:1071-1075`, `crates/stats/src/power.rs:1099-1110`, `crates/stats/src/power.rs:1151`, `crates/stats/src/power.rs:1555`, `crates/stats/src/power.rs:1730-1734`, and `crates/stats/src/power.rs:1794-1796` at that base (introduced in `52e18d7`)
- **Category:** wrong-result
- **Defect:** `compute_power_curve` (called unconditionally by `solve_power`) starts at `lo = min_integer_n()` without accounting for `n2 = allocation_ratio * n1 >= 1`, aborting `solve_power` whenever `allocation_ratio < 1.0` in `TwoProportions` or `< 0.5` in `TwoSampleUnpairedT`, and `ceiling_counts` independently ceils `n1` and `n2` without verifying `achieved_power >= target_power` under `PooledNullUnpooledAlt` where power is non-monotone in `n2` for small `k`.
- **Failure scenario:**
  1. **Unconditional `solve_power` failure for `k < 1`:** Any `TwoProportions` request with `allocation_ratio = 0.5` (2:1 Group 1 to Group 2 allocation) or any `TwoSampleUnpairedT` request with `allocation_ratio = 0.25` (4:1 allocation) succeeds in `solve_power_core` (unless `min_continuous_n` at `:1151` also hits `n2 < 1` first, returning `NotConverged`), then immediately fails in `compute_power_curve` at `nf = 1.0` (`n2 = 0.5 < 1.0`) or `nf = 2.0` (`n2 = 0.5 < 1.0`) with `Err(StatsError::InvalidParameter { name: "sample_size", value: 1.0 /* or 2.0 */ })`.
  2. **Under-powered integer sample size:** For `TwoProportions` (`PooledNullUnpooledAlt`, two-sided $\alpha = 0.05$, `target_power = 0.70`, `p1 = 0.001`, `p2 = 0.20`, `allocation_ratio = 0.05`), continuous root $n_1^* = 46.23$ ($n_2^* = 2.31$) achieves `0.7000`, but `ceiling_counts` rounds to $(n_1, n_2) = (47, 3)$, shifting the pooled null variance upward so `achieved_power = 0.6903 < 0.70`.
- **Evidence:**
  ```rust
  ResolvedEffect::TwoProportions { p1: Some(p1), p2: Some(p2), .. } => {
      let n2 = n2_explicit.unwrap_or(ctx.allocation_ratio * n1);
      if n1 < 1.0 || n2 < 1.0 {
          return Err(StatsError::InvalidParameter { name: "sample_size", value: n1 });
      }
      two_proportions_p_power(ctx, n1, n2, *p1, *p2)
  }
  ```
  Oracle (`Rscript --vanilla`, R 4.5.2): `two_proportions_p_power(n1 = 46.231, n2 = 2.3116) = 0.7000`, `two_proportions_p_power(n1 = 47, n2 = 3) = 0.6903 < 0.70`.
- **Suggested fix:** Enforce `n_min >= (1.0 / ctx.allocation_ratio)` (and `(2.0 - n1).max(1.0) / k` for `UnpairedT`) in both `min_continuous_n` and `compute_power_curve`'s `lo` bound, and after `ceiling_counts` in `SampleSize` mode, increment `n1` (recomputing `n2 = ceil(k * n1)`) while `achieved_power < target_power`.
- **Related:** `R2-S02-04`, `R2-S02-10`.
