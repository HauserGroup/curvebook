# Normalization and baseline oracle scope

Add numerical fixtures for normalization, baseline removal, and uncertainty propagation in mathematical transforms. The current suite includes basic transform values, a finite-difference propagation check, and a negative-divisor bounds regression. New fixtures will independently check reported anchors, rowwise arithmetic, and uncertainty on summarized measurements. [Transform specifications](../implementation/data-tables-and-transforms.md#5-derived-transforms-cratestransform) · [Existing transform tests](../../crates/transform/tests/unit_transform.rs)

## Proposed scope

Use small hand-computable sheets with unequal dataset ranges, inactive observations, and summarized SD or SEM. Derive expected values using exact arithmetic where practical and evaluate nonlinear endpoints and derivatives independently. Treat the two uncertainty modes according to their documented output layouts. [JCGM guide to uncertainty propagation](https://doi.org/10.59161/JCGM100-2008E)

## Acceptance criteria

- [x] Compare per-dataset and pooled anchors and every transformed value for both fraction and percentage output. Include an excluded extreme and a blank row, assert the emitted anchor values, and check that coincident anchors produce the documented typed error.
- [x] Use distinct leading and trailing windows to derive the baseline and interpolate it over row positions. Verify subtraction and ratio or percent change, including a zero-denominator row and a missing or excluded anchor observation.
- [x] Verify transformed centers and analytical first-order spreads for summarized SD or SEM. Independently calculate both endpoints for a nonlinear monotone transform and check lower and upper ordering for a decreasing transform. Include an out-of-domain case and assert the documented missing-value or warning behavior.
- [x] Exercise the public transform functions and check one typed analysis result. Record source inputs, expected cells and scalars, uncertainty conventions, and justified tolerances. Run the fixtures in the ordinary offline Rust suite with existing tolerances intact.

Curve smoothing and AUC, including the separate clipped fitted-curve case, are covered by [#30](https://github.com/HauserGroup/curvebook/pull/30).

## Reference provenance and conventions

- **Normalization and baseline removal:** The [normalization oracle suite](../../crates/transform/tests/d1_normalization.rs) tests unequal-range sheets (`[10, 90]` vs `[30, 190]`) with excluded extremes (`500*`, `-200*`), blank rows, `ControlColumnMean` + hooked `InfoConstant` anchors, coincident-anchor `TransformError::InvalidSpec` errors, row-wise `MeanSemN` baselines, and `FirstAndLastLinear { first_k: 2, last_k: 4 }` windowed row-position interpolation across `Difference`, `Ratio`, `PercentChange`, and `FractionalChange` (including exact zero-denominator crossing, missing window entry, and all-missing anchor window warning behavior). All linear values match exact `fractions.Fraction` values within `1e-12`.
- **Uncertainty propagation (`JCGM 100:2008`):** For `MeanSdN` / `MeanSemN` / `MeanCvN`, `FirstOrderDeltaMethod` evaluates $g(M)$ and $|g'(M)| \cdot s$, while `ReplicateEndpoints` retains the 3-subcolumn `[Mean, Spread, N]` layout and computes half-width $\frac{1}{2}|g(M + s) - g(M - s)|$ (preserving `N`); `UpperLowerLimits` (`[Mean, Lower, Upper]`), `MedianIqr` (`[Median, Q1, Q3]`), and `MeanLowHigh` (`[Mean, -Error, +Error]`) verify explicit lower/upper ordering (including partial out-of-domain and partial-missing limits) under decreasing monotone transforms (`Reciprocal`, `ConcentrationToNegativeLogM`) and domain-boundary blanking/warnings. Decreasing-slope `MeanLowHigh` offset swaps and partial-limit normalization/reversal were fixed in [`math.rs`](../../crates/transform/src/ops/math.rs) and [`normalize_baseline.rs`](../../crates/transform/src/ops/normalize_baseline.rs).
- **Independent corroboration:** The [reference generator](../../crates/transform/tests/reference/normalization.py) computes exact rationals via Python `fractions.Fraction` and nonlinear centers, derivatives, and endpoints via `mpmath 1.3.0` at 80 and 120 decimal digits (maximum inter-precision difference `7.044e-80`), corroborated with `R 4.5.2` to binary64 precision (`1e-12` assertion tolerance). The Rust suite runs completely offline using stored binary64 literals.
