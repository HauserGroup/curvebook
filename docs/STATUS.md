## Alpha launch and GUI readiness

**Milestone policy updated 2026-11-16:** Alpha means **full MCP functionality for the currently implemented engine scope, with known bugs acceptable**, launched under the **CurveBook** name. This covers actual MCP command discovery/execution, data and analysis/fitting workflows, graph/layout previews and exports, project persistence, batches, resources/prompts, and structured failures in the documented modes. Deferred features are outside the current Alpha scope. Known bugs and audit findings must remain documented; Alpha does not promise production reliability, stable interfaces, or full audit closure, and does not waive the project's scientific or engineering rules.

**Alpha released: [`v0.1.0-alpha.1`](https://github.com/HauserGroup/curvebook/releases/tag/v0.1.0-alpha.1) published as a GitHub prerelease on 2026-11-17 (`a5f54d7`, `24` assets incl. `SHA256SUMS.txt`).** [`R7.3`](planning/roadmap-history/r7.md#r73-mcp-workflow-parity-proof--shared-live-window) MCP functionality, [`R7.4`](planning/roadmap-history/r7.md#r74-accessible-mcp-guide-and-minimal-readme) onboarding, the [`R0.20`](planning/roadmap-history/r0.md#r020-rename-lumencraft-to-curvebook) CurveBook cutover (`HauserGroup/curvebook` origin, `0.1.0-alpha.1` workspace version, rerun `README.md` + `mcp-for-beginners.md` `--workdir` & `r73_mcp_*` acceptance, and [`alpha-known-issues.md`](release/alpha-known-issues.md)), and strict [`R0.21`](planning/roadmap-history/r0.md#r021-strict-alpha-branding-and-asset-provenance-gate) branding, MCP surface, clean-room, and asset-provenance clearance on the current workspace and local release artefacts ([`alpha-branding-clearance.md`](release/alpha-branding-clearance.md)) are verified.
