## Known Limits

1. **Recorded human walkthroughs, browser app & translations (`1.0` gates):** All `65 / 65` reference workflows pass automated five-stage `WorkflowRun` execution on the rendered `egui` desktop shell ([`R10.25`](history/roadmap/r10.md#r1025-automated-gui-completion-of-all-65-workflows-beta-gate), satisfying **Beta**). Still open for **1.0**: recorded computer-use or manual human walkthroughs on macOS desktop and browser ([`R10.13`](ROADMAP.md#r1013-human-operable-50-workflow-acceptance--manual-qa)), Windows/Linux desktop smoke QA ([`R10.24`](ROADMAP.md#r1024-windows--linux-desktop-gui-smoke-qa-10-gate)), rebuilding `apps/curvebook-web` onto `eframe::WebRunner` with in-browser tests ([`R11`](ROADMAP.md#r11-usable-browser-app) / [`R11.11`](ROADMAP.md#r1111-migrate-browser-host-to-eframe-webrunner-10-gate)), and native-speaker review of the `13` shipped non-English LTR/CJK `[Draft]` locales ([`R8.12`](ROADMAP.md#r812-desktop-rtl-gui-mirroring--native-speaker-translation-review-10-gate)). Desktop RTL (`ar`/`he`) GUI mirroring is unlikely and unscheduled.
2. **Cross-OS hardware QA, external commercial interoperability & Windows code signing (`R8.5`, `R8.9`, `R8.11`, `R17`):** Windows Authenticode signing ([`R8.11`](ROADMAP.md#r811-windows-authenticode-signing-after-beta); Beta `.msi` installers ship unsigned), Microsoft Store MSIX installation/certification ([`R8.9`](ROADMAP.md#r89-windows-msix-packaging--microsoft-store-distribution)), Windows/Linux VM desktop & idle-power QA ([`R8.5`](ROADMAP.md#r85-cross-os-hardware-cjkrtl-desktop-qa--installersigning-hardening), [`R17.3`](ROADMAP.md#r173-real-hardware-idle-power-and-large-project-responsiveness-pass)), interactive paste/import checks in Adobe Illustrator / Microsoft Word / PowerPoint ([`R17.2`](ROADMAP.md#r172-downstream-vector-and-document-export-interoperability)), and external GUI MCP host trials ([`R17.4`](ROADMAP.md#r174-live-llm-mcp-usability-trials-and-ergonomics-fixes)) require target hosts/software outside the local macOS environment.
3. **Remaining Beta blockers (hosted checks only — [`R14.1`](ROADMAP.md#r141-beta-release-pipeline), [`R0.36`](ROADMAP.md#r036-full-workspace-gap--delta-audit-remediation-beta-gate), [`R0.27`](ROADMAP.md#r027-user-first-readme-overhaul-beta-gate), [`R12.1`](ROADMAP.md#r121-documentation-site-on-github-pages)):** All local Beta code is landed on `main`, including desktop import/export + human-path tests ([`R10.29`–`R10.30`](history/roadmap/r10.md#r1029-desktop-import-and-export-gaps-beta-gate)), `.pzfx`/`.prism` GUI naming ([`R10.34`](history/roadmap/r10.md#r1034-main-gui-file-extension-naming-for-imported-project-files-beta-gate)), schema `v9` `.pzfx`/`.prism` interop & project merging ([`R22`](history/roadmap/r22.md#r22-external-scientific-file-compatibility--project-merging-beta-gate)), and local `GAP-01`–`GAP-07` / delta-audit fixes ([`R0.36`](ROADMAP.md#r036-full-workspace-gap--delta-audit-remediation-beta-gate)); Apple signing/notarization credentials and tag-protection rulesets are configured. Remaining Beta work: green hosted `ci.yml` on `main`, hosted Windows `.msi` `release-scan` confirmation, live GitHub Pages verification (`R12.1`), and one `v0.1.0-alpha.2` rehearsal release across `release.yml` verifying separated signing steps (`R0.36`) plus automated clean-runner macOS/Windows and README checks (`R14.1`, `R14.3`, `R0.27`). No Beta step needs direct human intervention.
4. **Full breaking cutover from pre-`R0.20` files:** CurveBook has zero readers, aliases, or migrations for pre-`R0.20` `.lumencraft`, `.lumencraft.d/`, `.lctemplate`, or `lumencraft.batch.v1` inputs, which are explicitly rejected ([`file-formats.md` §4](file-formats.md#4-breaking-cutover-legacy-rejection--residual-name-allowlist)).
