# CurveBook Status

> **Updated:** 2026-11-24 · **Docs index:** [`README.md`](README.md) · **Roadmap:** [`ROADMAP.md`](ROADMAP.md) · **Parity overview:** [`evidence/overview.md`](evidence/overview.md)

This document summarizes what works in CurveBook today, the checks that verify it, and the honest limits of the current workspace. Every Markdown table below uses unique Column 1 keys (`cargo xtask status`). To avoid stale prose numbers ([`CONTRIBUTING.md`](../CONTRIBUTING.md)), volatile file, line, test, and catalog-key counts are inspected on demand via `cargo xtask stats --exact` and `cargo xtask i18n-report`. Historical wave logs live in [`history/roadmap.md`](history/roadmap.md).

## Known Limits

1. **Recorded human walkthroughs, browser app & RTL desktop locales (`1.0` gates):** All `65 / 65` reference workflows pass automated five-stage `WorkflowRun` execution through the rendered `egui` desktop shell ([`R10.25`](history/roadmap/r10.md#r1025-automated-gui-completion-of-all-65-workflows-beta-gate), satisfying **Beta**; 2026-11-21 completion audit closed). Still open for **1.0**: recorded computer-use or manual human walkthroughs on macOS desktop and browser ([`R10.13`](ROADMAP.md#r1013-human-operable-50-workflow-acceptance--manual-qa)), Windows/Linux desktop smoke QA ([`R10.24`](ROADMAP.md#r1024-windows--linux-desktop-gui-smoke-qa-10-gate)), rebuilding `apps/curvebook-web` onto `eframe::WebRunner` with in-browser tests ([`R11`](ROADMAP.md#r11-usable-browser-app) / [`R11.11`](ROADMAP.md#r1111-migrate-browser-host-to-eframe-webrunner-10-gate)), native-speaker review of the `15` machine-drafted `[Draft]` locales, and desktop RTL (`ar`/`he`) completion.
2. **Cross-OS hardware QA, external commercial interoperability & Windows code signing (`R8.5`, `R8.9`, `R8.11`, `R17`):** Windows Authenticode signing ([`R8.11`](ROADMAP.md#r811-windows-authenticode-signing-after-beta); Beta `.msi` installers ship unsigned), Microsoft Store MSIX installation/certification ([`R8.9`](ROADMAP.md#r89-windows-msix-packaging--microsoft-store-distribution)), Windows/Linux VM desktop & idle-power QA ([`R8.5`](ROADMAP.md#r85-cross-os-hardware-cjkrtl-desktop-qa--installersigning-hardening), [`R17.3`](ROADMAP.md#r173-real-hardware-idle-power-and-large-project-responsiveness-pass)), interactive paste/import checks in Adobe Illustrator / Microsoft Word / PowerPoint ([`R17.2`](ROADMAP.md#r172-downstream-vector-and-document-export-interoperability)), external GUI MCP host trials ([`R17.4`](ROADMAP.md#r174-live-llm-mcp-usability-trials-and-ergonomics-fixes)), and external proprietary `.pzfx`/`.prism` corpus sweeps ([`R17.5`](ROADMAP.md#r175-real-world-legacy-project-import-hardening)) require target hosts/software outside the local macOS environment.
3. **Hosted GitHub Actions CI, live Pages & Beta rehearsal release ([`R14.1`](ROADMAP.md#r141-beta-release-pipeline), [`R12.1`](ROADMAP.md#r121-documentation-site-on-github-pages)):** Local policy, lint, test, docs-site, and packaging checks pass, and Apple signing/notarization credentials plus tag-protection rulesets are configured. Remaining Beta release steps require hosted execution after pushing `main`: green hosted `ci.yml` (`R14.1`, `R0.34`, `R0.35`, `R16.19`, `R17.1`), live GitHub Pages verification (`R12.1`), Windows hosted `.msi` `release-scan` confirmation, and one `v0.1.0-alpha.2` rehearsal release across `release.yml` with automated clean-runner macOS and Windows-upgrade checks (`R14.1`, `R14.3`, `R0.27`). Since 2026-11-24 no Beta step needs direct human intervention; the desktop import and export gaps ([`R10.29`](ROADMAP.md#r1029-desktop-import-and-export-gaps-beta-gate)) and their human-path tests ([`R10.30`](ROADMAP.md#r1030-human-path-tests-for-import-and-export-beta-gate)) are open Beta items.
4. **Full breaking cutover from pre-`R0.20` files:** CurveBook has zero readers, aliases, or migrations for pre-`R0.20` `.lumencraft`, `.lumencraft.d/`, `.lctemplate`, or `lumencraft.batch.v1` inputs, which are explicitly rejected ([`file-formats.md` §4](file-formats.md#4-breaking-cutover-legacy-rejection--residual-name-allowlist)).
