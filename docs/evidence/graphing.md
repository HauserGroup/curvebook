## Graph Families & Graphical Data Objects
- [x] **XY Graphs:** Scatter points, straight/staircase/spline connecting lines, area-under-curve fills, vertical & horizontal error bars (SD, SEM, $95\%$ CI, IQR, range, custom subcolumns; solid and **dashed/dotted** line styles), smooth fitted curves & confidence/prediction ribbons, plus §6.2 theoretical probability distribution overlays (continuous `Normal`/`StudentT`/`FisherF`/`ChiSquare` tail-shaded polygons and discrete `Binomial`/`Poisson` integer-step PMF lollipop/bar & step-CDF overlays)
- [x] **Column Graphs:** Bar + error bar, bar + deterministic beeswarm/scatter replicate overlay, aligned dot plot with mean/median crossbar, box-and-whisker (Tukey, min–max, percentile whiskers + outliers), violin plot (KDE + quartiles + points + half-violin), floating min–max bar, before–after paired subject lines
- [x] **Grouped Graphs:** Interleaved vs. Separated bars (`Column = Color/Legend`, `Row = X-Axis Cluster`, configurable `Row titles` / `Column titles` categorical axis ticks), stacked bars, grouped scatter/beeswarm + bars, grouped box-and-whisker, grouped violin, superimposed interaction symbols + connecting lines
- [x] **Contingency & Parts of Whole:** Interleaved/stacked count & percentage bars, $100\%$ stacked fraction bar, ring/donut, and pie
- [x] **Survival Graphs:** Kaplan–Meier staircase curve, censored tick marks, shaded/dashed Greenwood $95\%$ CI envelope, axis-aligned **Number at Risk** table, and **Cox PH baseline + covariate-profile survival overlays** (`cox-profile-survival`, `cox_profile:{idx}`)
- [x] **Multiple Variables Graphs:** Five-channel bubble/multivariate scatter (`X`, `Y`, `Color` discrete/continuous ramp, `Size` continuous/categorical, point `Label` text) with non-modal `Apply`, group convex hulls & confidence ellipses, plus **categorical $\times$ continuous GDOs** (bars, box-and-whisker, violin, column scatter, summary connecting lines) with independent graph-level categorical ordering
- [x] **Diagnostic & Specialized:** Grouped, correlation & parameter-correlation (`ParameterCorrelationHeatmap`) heatmaps (with colorbar), Volcano plot ($-\log_{10} p$ / $-\log_{10} q$ vs. effect), Bland–Altman plot, ROC curve (standalone & `glm-logistic-roc`), Forest / parameter-CI plot, Homoscedasticity plot (`HomoscedasticityPlot`), Actual vs. Predicted + Hosmer–Lemeshow calibration plot (`ActualVsPredictedPlot`), Residual vs. Row Order plot (`ResidualVsRowPlot`, GLM & Cox–Snell), Gap Statistic optimal-$k$ plot (`GapStatisticPlot`), and Normal / Lognormal Q–Q plots (`NormalQqPlot`, `LognormalQqPlot`)

## Axes, Nonlinear Scales & Framing
- [x] Scale transforms: Linear, $\log_{10}$, $\log_2$, $\ln$ (with safe non-positive omission & lower error-bar floor clipping), $\text{logit}$, $\text{probit}$ (probability $\%$), and reciprocal ($1/X$)
- [x] Discontinuous / broken axes (2 or 3 segments with independent domain/scale/tick intervals, configurable gap width, and slash/zigzag ornaments)
- [x] Framing presets: open L-frame, Tufte offset range frame, plain boxed, dual Y axes (`Left Y` + `Right Y2`), and origin-crossing axes
- [x] Major/minor ticks, logarithmic minor cadences, power-of-10 superscripts ($10^{-6}$), antilog labels, additional ticks/gridlines, and shaded threshold bands *(major/minor ticks, log minor cadences, power-of-10 superscripts, antilog labels, gridlines, shaded `AxisThreshold` zones, and `AdditionalTick` mapped across all 7 scales & broken segments via `compute_additional_ticks` and `graph.setAdditionalTicks` verified)*
