# Interop Format Evidence Ledger (`.pzfx` and `.prism`)

This tracked ledger records every structural fact CurveBook relies on for reading and writing `.pzfx` and `.prism` files, together with its source, confidence level, and dependent subsystems. Detailed per-file hashed observations and dialect profiles live in the gitignored local ledger (`plan/format-observations/`, generated by `cargo xtask interop-corpus --observe`).

**Clean-room boundary:** This document records structural observations and public standards only. It contains zero corpus filenames, zero user titles or cell values, and zero vendor prose.

## 5. `.prism` Integrity / Opaque Entries & Conformance Verdict

1. **No JSON checksum keys:** Zero checksum, hash, digest, or signature keys appear in any `.prism` JSON file.
2. **Mandatory undocumented `.dt` tokens (`27,893` entries):** `data/tables/<uid>/data.dt` appears in **`960 / 960` (`100%`)** valid deduplicated `.prism` archives (`20,872` entries) and `analyses/<uid>/parameters.dt` appears in **`686 / 686` (`100%`)** archives with analyses (`7,021` entries). Every sampled `.dt` file (`685 / 685`) is a **32-character lowercase ASCII hex string** (128-bit deterministic token that recurs across files for identical/empty tables or default parameter sets) and matches `0 / 685` single-file CRC32, MD5, SHA-1, or SHA-256 digests of sibling files — indicating an undocumented composite/internal serialization digest.
3. **Legacy `PCFF` binary blobs (`24,220` `.bin` entries):** `graphs/<uid>/data.bin` (`6,978`) and `layouts/<uid>/data.bin` (`592`) carry `PCFFGRA4` binary magic; `misc/used_fonts.bin` (`933 / 960` files) carries `PCFF ` binary magic; `misc/<uid>.bin` (`15,717` entries) are opaque binary structs (`18 00 00 00 ...`). In total, `55,471` non-CSV/JSON/image opaque entries occur across `979 / 983` `.prism` archives.
4. **Beta shipping verdict:**
   - **`.prism` import:** Fully supported from open UTF-8 JSON, headerless CSV, and raster preview PNGs, with opaque `PCFFGRA4` graph/layout definitions explicitly surfaced via typed warnings rather than decoded or silently dropped.
   - **`.prism` export:** **Import-only for Beta** (experimental `.prism` writer stays hidden behind an experimental flag with no GUI menu entry). Because `data/tables/<uid>/data.dt` is a `100%`-present non-excluded entry in `archive-dialect-profile.json` whose 128-bit digest algorithm is undocumented (and graph/font `.bin` entries are legacy `PCFF` binaries), an independent `.prism` writer cannot satisfy the automated corpus-conformance bar without risking silent rejection by external readers. **`.pzfx`** — whose 100%-present non-excluded grammar is fully open UTF-8 XML — serves as CurveBook's conformant Beta interchange export format (data tables and info sheets only, with an explicit preflight summary and `ExportReport` listing dropped non-tabular items).
