# Interop Format Evidence Ledger (`.pzfx` and `.prism`)

This tracked ledger records every structural fact CurveBook relies on for reading and writing `.pzfx` and `.prism` files, together with its source, confidence level, and dependent subsystems. Detailed per-file hashed observations and dialect profiles live in the gitignored local ledger (`plan/format-observations/`, generated by `cargo xtask interop-corpus --observe`).

**Clean-room boundary:** This document records structural observations and public standards only. It contains zero corpus filenames, zero user titles or cell values, and zero vendor prose.

## 5. `.prism` Integrity / Opaque Entries & Conformance Verdict

1. **No JSON checksum keys:** Zero checksum, hash, digest, or signature keys appear in any `.prism` JSON file.
2. **Mandatory undocumented `.dt` tokens (`27,893` entries):** `data/tables/<uid>/data.dt` appears in **`960 / 960` (`100%`)** valid deduplicated `.prism` archives (`20,872` entries) and `analyses/<uid>/parameters.dt` appears in **`686 / 686` (`100%`)** archives with analyses (`7,021` entries). Every `.dt` entry is a **32-character lowercase ASCII hex string** (128-bit uniform hex, not UUIDv3/v4/v5). Exhaustive cross-archive analysis of all `979` readable corpus ZIPs shows that `data.dt` is a **strict 1-to-1 deterministic function of the exact raw bytes of `data.csv` alone** (`0 / 15,097` distinct CSV payloads had more than one `data.dt`; all `1,483 / 1,483` empty 0-byte CSVs across varying row/column counts, archive versions, and UIDs map to `130ab2f63ec643bee541b74c960e10db`), and `parameters.dt` is a **strict 1-to-1 deterministic function of the exact raw bytes of `parameters.json` alone** (`0 / 2,818` distinct raw payloads diverged). Neither digest matches any standard unkeyed cryptographic or non-cryptographic 128-bit hash tested (CRC32, MD2/4/5, RIPEMD-128, SHA-1, SHA-224/256/384/512, SHA-3, BLAKE2b/s, BLAKE3, SHAKE128/256, XXH3-128, FNV-1a-128, CityHash128, SpookyHash128, SipHash-128, or MurmurHash3 — including byte/word-swapped variants and an exact algebraic `fmix64` inversion ruling out all 2^64 seeds of `MurmurHash3_x64_128`), indicating a **keyed, salted, or custom proprietary 128-bit external-edit digest**.
3. **Legacy `PCFF` binary blobs (`24,220` `.bin` entries):** `graphs/<uid>/data.bin` (`6,978`) and `layouts/<uid>/data.bin` (`592`) carry `PCFFGRA4` binary magic; `misc/used_fonts.bin` (`933 / 960` files) carries `PCFF ` binary magic; `misc/<uid>.bin` (`15,717` entries) are opaque binary structs (`18 00 00 00 ...`). In total, `55,471` non-CSV/JSON/image opaque entries occur across `979 / 983` `.prism` archives.
4. **Beta shipping verdict:**
   - **`.prism` import:** Fully supported from open UTF-8 JSON, headerless CSV, and raster preview PNGs, with opaque `PCFFGRA4` graph/layout definitions explicitly surfaced via typed warnings rather than decoded or silently dropped.
   - **`.prism` export:** **Import-only for Beta** (experimental `.prism` writer stays hidden behind an experimental flag with no GUI menu entry). Because `data/tables/<uid>/data.dt` is a `100%`-present non-excluded entry in `archive-dialect-profile.json` whose 128-bit digest algorithm is undocumented (and graph/font `.bin` entries are legacy `PCFF` binaries), an independent `.prism` writer cannot satisfy the automated corpus-conformance bar without risking silent rejection by external readers. **`.pzfx`** — whose 100%-present non-excluded grammar is fully open UTF-8 XML — serves as CurveBook's conformant Beta interchange export format (data tables and info sheets only, with an explicit preflight summary and `ExportReport` listing dropped non-tabular items).

   - Across the `423` Tukey analyses, `52` analyses (`137 / 6,080` pairwise adjusted *p*-values, all `bound = Equal`) showed absolute differences in `[1.14e-9, 4.76e-6]` (`p50 = 9.07e-9`, `p95 = 1.91e-6`, `max = 4.76e-6`) at small residual degrees of freedom (`df = 5..8`) and far-right-tail quantiles (`q = 10..33`, `p ~ 1e-7..1e-3`).

   - CurveBook's statistical kernel stays exact and unchanged (`D1`); `CachedPairwiseLink::p_abs_tol = Some(1e-5)` applies solely to pairwise *p*/*q* comparisons on `ordinaryAnovaModel.multipleComparisons.tests`, while omnibus scalars and pairwise `|meansDifference|` stay at `abs_tol = 1e-9` / `rel_tol = 1e-6`. Cached inequality states (`P_VALUE_LESS`, `P_VALUE_GREATER`) are evaluated as bounds (`CachedBound`), and non-`"VALID"` pairwise entries are skipped.
3. **Untranslated-option guards keeping promoted designs at 100% clean agreement:**
   - **Additive two-way ANOVA (`includeInteractionTerm: false`):** `translate_two_way_anova` blocks `options.includeInteractionTerm == false` (main-effects-only models without an interaction term), keeping them as read-only snapshots; the remaining `71 / 71` full-interaction models agree 100% across all 7 Type III omnibus scalars.
   - **Outlier replicate handling (`SUB_COLUMN` and multi-subcolumn `AVERAGE`):** `translate_outliers` blocks `SUB_COLUMN` and unknown `data.handleReplicatesAs` values, and `check_source_sheet_option_compatibility` blocks `IDENTIFY_OUTLIERS` when `data.handleReplicatesAs` is absent or `"AVERAGE"` on a multi-subcolumn source table (`> 1` Y subcolumn).
