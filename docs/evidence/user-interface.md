## Risk Spike `S1` Decision (Spreadsheet Grid at 60 fps): **GO**

- **Decision:** **GO** — virtualized two-tier spreadsheet engine (`curvebook-tools::GridToolState`) + sparse window formatter (`curvebook-ui-egui::GridViewState`). No redesign required.
- **Measured Evidence (`1,000 × 1,000 = 1,000,000 cells`):**
  - `curvebook-tools` (`spike_s1_grid_perf`, dev `opt-level=1`, `120` frames): `min = 0.0340 ms`, `p50 = 0.0390 ms`, `p95 = 0.0432 ms`, `max = 0.0612 ms`, `mean = 0.0392 ms`; `1,000,000`-row tail jump `elapsed = 0.0150 ms` (`62` visible cells).
  - `curvebook-ui-egui` (`grid_perf_s1`): `SPIKE_S1_UI_1M` grouped scroll (`120` frames) -> `p50 = 0.061 ms`, `p95 = 0.507 ms`, `mean = 0.245 ms`, `max = 7.795 ms` (`37 × 14` visible cells); `Select All (1,000,000 cells)` + batched `table.excludeCells` -> `0.044 ms` (`intents = 1`, `quick_stats` capped at `50,000` cells); `multivar 30 frames` -> `mean = 0.069 ms`, `max = 1.246 ms`.
  - Paste (`ImportPasteWizardState`) and `table.excludeCells` round-trips dispatch cleanly through `Engine` commands well inside the `16.67 ms` 60-fps frame budget.
- **Scope note:** `S1` benchmarks the virtualized formatting layer; interactive rendered grid scrolling & keyboard navigation are covered by `r15_4_grids_and_ingestion::one_million_cell_xy_and_mv_virtualization_regression_guard`, `r15_2_anova_and_1m_bench::r15_2_egui_1m_column_ci_smoke`, and `r10_core_and_spike::r10_22_one_million_cell_virtualized_grid_frame_budget`.
