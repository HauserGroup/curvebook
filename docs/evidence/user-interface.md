> **How to read this checklist (revised 2026-11-15).** Earlier revisions ticked `[x]` when a `UiApp` state machine existed and the semantic `gui_only` agent harness (`dispatch_gui_action`, `ui.inspect`, `ui.invoke_menu` with structured params, `ui.answer_dialog` field patches) could drive it. A human-GUI audit found that most of those surfaces are not drawn as interactive widgets in the desktop window or web canvas. From this revision:
>
> - `[x]` means **a person can operate it in the rendered GUI** (desktop, and web where noted) using pointer and keyboard.
> - `[ ]` means it is not human-operable yet. Each line states whether the **state machine / agent harness** exists and which `R10` item makes it human-operable.
>
> **Architecture note:** `curvebook-ui-egui` (`L6`) holds the `UiApp` state shell, the `legacy` `LayoutTree` + deterministic CPU RGBA/PNG compositor (`render_workspace_rgba`, `HumanPathDriver`), and the incremental `R15` native `egui` desktop shell (`EguiHumanPathDriver` + `egui_kittest` AccessKit inspection under `--ui-backend=egui`, defaulting to `legacy` until `R15.5`). The native app (`apps/curvebook`, `eframe`/`egui`/`wgpu` + `rfd`) hosts the desktop window; the web app (`apps/curvebook-web`, deferred post-Beta under `R11`/`R11.11`) blits the compositor buffer to WebGL2 (`window.CurveBookHost`). Per [`ROADMAP.md`](../ROADMAP.md#r15-modern-egui-desktop-gui-overhaul-beta-gate), `WF-01`–`WF-50` human-path counts are tracked per desktop backend (`50/50 legacy, 0/50 egui` at `R15.4` Phase A), enforced by `cargo xtask status` (`Pitfalls §6`). Test counts and live metrics are in [`STATUS.md`](../STATUS.md).

## Risk Spike `S1` Decision (Spreadsheet Grid at 60 fps): **GO**

- **Decision:** **GO** — virtualized two-tier spreadsheet engine (`curvebook-tools::GridToolState`) + sparse window formatter (`curvebook-ui-egui::GridViewState`). No redesign required.
- **Measured Evidence (`1,000 × 1,000 = 1,000,000 cells`):**
  - `curvebook-tools` (`spike_s1_grid_perf`, dev `opt-level=1`, `120` frames): `min = 0.0340 ms`, `p50 = 0.0390 ms`, `p95 = 0.0432 ms`, `max = 0.0612 ms`, `mean = 0.0392 ms`; `1,000,000`-row tail jump `elapsed = 0.0150 ms` (`62` visible cells).
  - `curvebook-ui-egui` (`grid_perf_s1`): `SPIKE_S1_UI_1M` grouped scroll (`120` frames) -> `p50 = 0.061 ms`, `p95 = 0.507 ms`, `mean = 0.245 ms`, `max = 7.795 ms` (`37 × 14` visible cells); `Select All (1,000,000 cells)` + batched `table.excludeCells` -> `0.044 ms` (`intents = 1`, `quick_stats` capped at `50,000` cells); `multivar 30 frames` -> `mean = 0.069 ms`, `max = 1.246 ms`.
  - Paste (`ImportPasteWizardState`) and `table.excludeCells` round-trips dispatch cleanly through `Engine` commands well inside the `16.67 ms` 60-fps frame budget.
- **Scope note:** `S1` benchmarks the virtualized formatting layer; interactive rendered grid scrolling & keyboard navigation are covered by `r10_w5_grid_core::{r10_8_two_axis_scroll_scrollbar_and_never_canvas_zoom, r10_8_keyboard_navigation_selection_boundary_and_clear}` and `r10_core_and_spike::r10_22_one_million_cell_virtualized_grid_frame_budget`.
