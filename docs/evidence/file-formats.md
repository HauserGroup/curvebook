## Native FAIR-Aligned Project Formats
- [x] `.curvebook` ZIP container and `.curvebook.d/` unpacked Git-friendly directory format (`save_project_unpacked_dir` / `open_project_unpacked_dir`, `manifest.json` with `schema_version`, sheet catalog, CSV data tables, JSON Info/analysis/fit/graph/layout specs, `CellExclusionNote` provenance sidecars, `NamedCheckpoint` snapshots, and optional cached results; verified in `curvebook-format` and `curvebook-engine` suites, including Wave 6 `G2` linked-file error propagation). Full breaking cutover: legacy `.lumencraft` / `lumencraft-archive` payloads are explicitly rejected (`file-formats.md` §4).
- [x] `.cbtemplate` reusable method & project template (empty or placeholder data tables pre-wired to transforms, statistical analyses, curve fits, styled graphs, and figure layouts)
- [x] Forward/backward schema migration harness (`CURRENT_SCHEMA_VERSION = 9`, `v2..v9` forward migrations and `v10+` forward refusal), circular-hook recovery guard, and crash-recovery journal (`MIGRATION_STEPS`, `sanitize_circular_hooks`, and `CrashRecoveryJournal` WAL `v2` + torn-tail replay via desktop `DirectoryJournalBackend` & in-memory `MemoryJournalBackend` verified in `curvebook-format` and `curvebook-engine` suites)
- [x] Generic project merging (`project.merge`, `sheet.clearOrigin`, consolidated `SheetId` renumbering in `curvebook-doc`, and `SheetOrigin` navigator badges across `.curvebook`, `.curvebook.d/`, `.cbtemplate`, `.pzfx`, `.prism`, and `.xlsx`; landed in `R22.6`)

## Tabular & Scientific Project Interchange
- [x] RFC-4180 CSV and TSV import/export with configurable delimiter (`,` / `;` / `\t`), quote character, header row count, missing-value sentinels (`NA`, `NaN`, blank), decimal separator (`.` vs. `,`), UTF-8/UTF-16 BOM handling, and range/filter/multi-block split options (`R17.1`, `R17.7`)
- [x] Pure-Rust `.xlsx` workbook import (`crates/format/src/xlsx.rs`, `table.importXlsx`) with multi-sheet selection, merged-cell fill, range/preamble extraction, and `MissingCachedValue` uncached-formula diagnostics (`R17.1`, `R17.6`, `R17.7`)
- [x] Clean-room `.prism` ZIP container import and export (`curvebook-format`, `table.importPrism`, `project.exportPrism`): routes native `data_sheets`, external ID-indexed `sheets`/`sheetAttributesMap`, and generic CSV ZIPs; bounded ZIP64 & cumulative decoded-byte caps; preserves imported result snapshots as `ResultProvenance::Imported` (`R22.5`, [`interop-format-notes.md`](interop-format-notes.md))
- [x] Clean-room `.pzfx` XML import and data-only export (`crates/format/src/pzfx/`, `table.importPzfx`, `project.exportPzfx`): UTF-8/UTF-16/ISO-8859-1/Windows-1252/MacRoman decoding, rich-text super/subscripts, `MeanSd`/`MeanSem` & Column summary modes, excluded-cell masks, Info constants, explicit refusal of legacy binary `.pzf` / `PCFF` payloads, authoritative `MAX_IMPORT_CELLS = 10_000_000` check, and `3,719`-file corpus verification (`R22.1`–`R22.5`, [`interop-format-notes.md`](interop-format-notes.md))
- [x] Tidy CSV and structured JSON export of all `ResultSheet` statistical tables, post-hoc comparisons, residuals, and nonlinear regression parameters for R / Python / Snakemake / Nextflow pipelines

## Publication Figure Export
- [x] Vector **SVG** export (`curvebook-svg`) with editable `<text>` (preserving super/subscripts) or outlined glyph paths, crisp clip regions, and deterministic output *(structurally validated in `curvebook-svg` tests & CLI Slice 0; interactive GUI viewer inspection not performed locally)*
- [x] Direct vector **PDF 1.7** export (`curvebook-pdf`) with optional embedded SFNT `/FontFile2` fonts (or Core-14 + outlined fallback), sRGB or print CMYK colour spaces, and exact `MediaBox` / `TrimBox` / `BleedBox` physical dimensions *(pure-Rust `%PDF-1.7` default / `--pdf-version 1.4|1.7`, optional `/FontFile2` SFNT embedding via `--ttf-font` or `CURVEBOOK_FONTS_DIR`, Core-14 Helvetica/Symbol + outlined fallback, `FlateDecode`, sRGB/CMYK/Grayscale, `/MediaBox`/`/TrimBox`/`/BleedBox`, 20-byte `xref`, and Wave 5 multi-engine Poppler `pdftoppm` + Ghostscript `gs` pixel QA `external_viewer_qa` across Latin, CJK, and RTL verified)*
- [x] High-DPI raster **PNG**, uncompressed/Deflate/LZW **TIFF**, and pure-Rust **ECMA-234 `.emf`** export (`72`–`1200` DPI, transparent/white/custom fill, `encode_emf`, and Wave 5 `G11` `MAX_RASTER_PIXELS = 67_108_864` / `try_reserve_exact` memory safety)
