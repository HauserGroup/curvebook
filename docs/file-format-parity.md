## Native FAIR-Aligned Project Formats
- [x] `.lumencraft` ZIP container and `.lumencraft.d/` unpacked Git-friendly directory format (`save_project_unpacked_dir` / `open_project_unpacked_dir`, `manifest.json` with `schema_version`, sheet catalog, CSV data tables, JSON Info/analysis/fit/graph/layout specs, `CellExclusionNote` provenance sidecars, `NamedCheckpoint` snapshots, and optional cached results; verified in `lumencraft-format` `51 passed` and `lumencraft-engine` `76 passed`, including Wave 6 `G2` linked-file error propagation)
- [x] `.lctemplate` reusable method & project template (empty or placeholder data tables pre-wired to transforms, statistical analyses, curve fits, styled graphs, and figure layouts)
- [x] Forward/backward schema migration harness, circular-hook recovery guard, and crash-recovery journal (`MIGRATION_STEPS`, `sanitize_circular_hooks`, and `CrashRecoveryJournal` WAL + torn-tail replay via desktop `DirectoryJournalBackend` & web-storage JSON model `MemoryJournalBackend` verified in `recovery_and_interop_parity`; browser `wasm32` Web Locks runtime awaits `wasm32` sysroot in `G6`)

## Tabular & Scientific Project Interchange
- [x] RFC-4180 CSV and TSV import/export with configurable delimiter (`,` / `;` / `\t`), quote character, header row count, missing-value sentinels (`NA`, `NaN`, blank), and decimal separator (`.` vs. `,`)
- [x] Clean-room `.prism` ZIP container import (reading standard CSV data sheets + JSON sheet/table metadata from public format conventions; bounded ZIP entry count and uncompressed byte ceiling)
- [x] Clean-room legacy `.pzfx` XML import (data tables, replicate subcolumn layouts, row/column titles with super/subscripts, excluded-cell masks, and Info constants; bounded XML nesting depth, zero external entities, and Wave 5 `G10` authoritative `MAX_IMPORT_CELLS = 10_000_000` check against `DataSheet::allocated_cell_slots()`)
- [x] Tidy CSV and structured JSON export of all `ResultSheet` statistical tables, post-hoc comparisons, residuals, and nonlinear regression parameters for R / Python / Snakemake / Nextflow pipelines

## Publication Figure Export
- [x] Vector **SVG** export (`lumencraft-svg`) with editable `<text>` (preserving super/subscripts) or outlined glyph paths, crisp clip regions, and deterministic output *(structurally validated in `lumencraft-svg` tests & CLI Slice 0; interactive GUI viewer inspection not performed locally)*
- [x] Direct vector **PDF 1.7** export (`lumencraft-pdf`) with optional embedded SFNT `/FontFile2` fonts (or Core-14 + outlined fallback), sRGB or print CMYK colour spaces, and exact `MediaBox` / `TrimBox` / `BleedBox` physical dimensions *(pure-Rust `%PDF-1.7` default / `--pdf-version 1.4|1.7`, optional `/FontFile2` SFNT embedding via `--ttf-font` or `LUMENCRAFT_FONTS_DIR`, Core-14 Helvetica/Symbol + outlined fallback, `FlateDecode`, sRGB/CMYK/Grayscale, `/MediaBox`/`/TrimBox`/`/BleedBox`, 20-byte `xref`, and Wave 5 multi-engine Poppler `pdftoppm` + Ghostscript `gs` pixel QA `external_viewer_qa` across Latin, CJK, and RTL verified; `14 passed`)*
- [x] High-DPI raster **PNG**, uncompressed/Deflate/LZW **TIFF**, and pure-Rust **ECMA-234 `.emf`** export (`72`–`1200` DPI, transparent/white/custom fill, `encode_emf`, and Wave 5 `G11` `MAX_RASTER_PIXELS = 67_108_864` / `try_reserve_exact` memory safety; `lumencraft-render`: `12 passed`)
