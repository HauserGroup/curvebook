CurveBook

File formats · .pzfx · .prism

Open .pzfx and .prism files.
Export the tables to CSV.

CurveBook is a free, open-source biostatistics and graphing application that reads the data tables in .pzfx and .prism files. You can list the tables, export any of them to CSV, or convert the whole file to a CurveBook project and analyse the data again. It runs offline on macOS, Windows, and Linux, needs no account, and never uploads your files.

  • Free & open source
  • Offline
  • macOS · Windows · Linux

Import scope

What CurveBook reads from these files

  • .pzfx files (XML): every data table, including XY, column, grouped, survival, and contingency tables, with replicate and summary (mean with SD or SEM) subcolumns, row and column titles, excluded values, and info notes.
  • .prism files (ZIP archives): the data tables stored inside the archive as CSV or TSV, with their table and info metadata when present. Parts CurveBook does not recognise are skipped and listed as warnings, so you can see exactly what was left out.
  • Not imported: graphs, analysis results, and page layouts. Rerun the analyses in CurveBook on the imported tables; its methods and their published references are listed in the analyses reference.
  • Read only: CurveBook opens these formats but does not write them. Save your work as a .curvebook project, or export tables to CSV or TSV.

Command line · curvebook-cli

Export the tables to CSV

Every CurveBook download includes the curvebook-cli command-line tool next to the desktop app. Open a terminal in the folder that holds your file.

1. See which tables the file contains

curvebook-cli info experiment.pzfx

The output lists each table with its ID, type, title, and size, followed by any import warnings.

2. Export a table to CSV

curvebook-cli convert experiment.pzfx experiment.csv

Without further options, the first table is exported. Pick another table by its title or ID:

curvebook-cli convert experiment.pzfx groups.csv --sheet "Groups"

Replicate subcolumns appear as side-by-side columns, and an excluded value keeps its number with a trailing * (for example 55*), so no data are silently dropped. Use a .tsv file name for tab-separated output.

3. Or convert the whole file to a CurveBook project

curvebook-cli convert experiment.pzfx experiment.curvebook

The project keeps all tables together, ready for analyses, curve fits, and graphs. The same commands work for .prism files. The full option list is in the command-line reference, and the files, import & export reference covers every supported format.

Prefer to work through an AI assistant? CurveBook’s local MCP server can import these files too; see MCP setup.

Good to know

Limits and privacy

  • Local only: files are read on your computer. CurveBook makes no network connections and collects no telemetry (Privacy Policy).
  • Size limits: very large files and archives are refused with an error message instead of being read partially. The exact limits are in the files reference.
  • Problems: if a file does not open as expected, check the known issues or report it on GitHub Issues; please share a file only if its data can be made public.
