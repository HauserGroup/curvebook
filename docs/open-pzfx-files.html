Import and export

What CurveBook reads and writes

Format Import (read) Export (write) Notes
.pzfx (XML) All 8 table types, info sheets, exclusions, rich text, notes Data tables and info sheets only Analyses, graphs, and layouts stay in .curvebook.
.prism (ZIP) All 8 table types, info sheets, exclusions, read-only results, graph previews when available Import only during Beta Proprietary binary data and undocumented digest files prevent safe export. Export to .pzfx or CSV instead.
.pzf / binary PCFF Not supported (CurveBook shows a clear error) Not supported Legacy binary format; re-save as XML .pzfx or .prism first.
.curvebook / .curvebook.d/ Full project Full project Open format described by a JSON Schema, with no proprietary binary data.
  • Importing files: CurveBook opens tables, exclusions, rich text, and info sheets from XML .pzfx and .prism files. Stored .prism results open as read-only snapshots, with graph previews when available, and are never used in calculations. Binary .pzf and PCFF files are refused with a clear message. Re-save them as XML .pzfx or .prism first.
  • Exporting to .pzfx: .pzfx export saves your data tables and info sheets only. Analyses, graphs and layouts stay in your .curvebook project. Each export writes a separate copy and lists any items it leaves out. Written to match the .pzfx structure of real files; not tested in other applications.
  • Merging projects: Choose File › Merge Project… to copy sheets from another .curvebook, .pzfx, .prism, or .xlsx file. Copied sheets get origin badges that you can remove.

See the files reference for full format coverage. To compute fresh results, re-run analyses in CurveBook.

Why .prism files are not truly FAIR

A .prism file is a ZIP archive of CSV and JSON files, so it is often called FAIR (Wilkinson et al., Scientific Data, 2016) ↗. Without a published schema, three barriers remain:

  • Raw CSVs lose headers and exclusions: The unzipped CSV files have no column titles or outlier masks, so R, Python, or Excel silently include excluded points.
  • Graphs stay locked in binary: Figures and layouts are stored as proprietary binary data.
  • Undocumented digest files block writing: Companion integrity files prevent independent tools from writing .prism archives safely.

Proprietary formats slow down science. Publicly funded data belong to science, not to a vendor's license. Read our empirical .prism and .pzfx specification, or save your work in the open .curvebook format.

Desktop app

Open, merge, and export in the desktop app

  1. Open or merge: Choose File › Open… or File › Import to open a .pzfx or .prism file. To add its sheets to an open project instead, choose File › Merge Project….
  2. Review warnings and snapshots: Unsupported items are listed under Import Warnings. On a read-only .prism snapshot, click Re-run as a CurveBook analysis… to compute fresh results.
  3. Export tables: Choose File › Export › CSV Table… to export one table, or Export All Data Tables… to export every table to a folder. Choose File › Export › .pzfx file… to export data tables and info sheets.

Command line

Convert and export from the command line

Every download includes curvebook-cli alongside the desktop app. Open a terminal in the folder that contains your file.

1. List the tables in a file

curvebook-cli info experiment.pzfx

This lists each table's ID, type, title, size, and any import warnings.

2. Export a table to CSV

curvebook-cli convert experiment.pzfx experiment.csv

This exports the first table. To pick another table, give its title or ID:

curvebook-cli convert experiment.pzfx groups.csv --sheet "Groups"

Replicates stay side by side, and excluded values keep a trailing * (for example, 55*). Use a .tsv file name for tab-separated output.

3. Convert the whole file to a CurveBook project

curvebook-cli convert experiment.pzfx experiment.curvebook

The project keeps every table together for analyses, fits, and graphs. The same commands also work on .prism files.

4. Export tables and info sheets to .pzfx

curvebook-cli convert experiment.curvebook export.pzfx

This writes a data-only .pzfx copy without changing your project, and lists any items it leaves out. See the CLI reference for all options, or MCP setup to use an AI assistant.

Good to know

Limits and privacy

  • Local only: Your files stay on your computer, with no telemetry or network calls (Privacy Policy).
  • Size limits: CurveBook refuses oversized files instead of reading them partially. The files reference lists the exact limits.
  • Problems: Check the known issues, or report a bug on GitHub Issues. Share only data that can be public.
