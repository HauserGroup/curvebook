Import & export scope

What CurveBook reads and writes

Format Import (read) Export (write) Notes
.pzfx (XML) All 8 table types, info sheets, exclusions, rich text, notes Data tables & info sheets only Analyses, graphs, and layouts stay in .curvebook.
.prism (ZIP) All 8 table types, info sheets, exclusions, read-only results, graph previews Import-only at Beta Proprietary binary blobs and undocumented digest files block safe export.
.pzf / binary PCFF Not supported (clear error) Not supported Legacy binary format; re-save as XML .pzfx or .prism first.
.curvebook / .curvebook.d/ Full project Full project Open JSON Schema format with no proprietary binary blobs.
  • Importing files: Open tables, exclusions, rich text, and info sheets from XML .pzfx and .prism files. Stored .prism results open as read-only snapshots (with graph previews) and never feed calculations. Binary .pzf and PCFF files are refused cleanly; re-save as XML .pzfx or .prism first.
  • Exporting to .pzfx: .pzfx export saves your data tables and info sheets only. Analyses, graphs and layouts stay in your .curvebook project. Each export writes a separate copy and lists dropped items. Written to match the .pzfx structure of real files; not tested in other applications.
  • Why .prism is import-only: Real .prism archives depend on undocumented binary and digest entries. Use .pzfx or CSV export at Beta.
  • Merging projects: Choose File › Merge Project… to copy sheets from another .curvebook, .pzfx, .prism, or .xlsx file with removable origin badges.

See the files reference for full format coverage, or re-run analyses in CurveBook.

Why .prism files are not truly FAIR

A .prism file is a ZIP of CSV and JSON files, so it is often called FAIR (Wilkinson et al., Scientific Data, 2016) ↗. Without a published schema, three barriers remain:

  • Raw CSVs lose headers and exclusions: Unzipped CSVs lack column titles and outlier masks, so R, Python, or Excel silently include excluded points.
  • Graphs stay locked in binary: Figures and layouts are stored as proprietary binary blobs.
  • Undocumented digest files block writing: Companion integrity files stop independent tools from safely writing .prism archives.

Proprietary formats slow down science. Publicly funded data belong to science, not a vendor license. Read our empirical .prism and .pzfx specification, or save natively in the open .curvebook format.

Desktop app

Open, merge, and export in the desktop app

  1. Open or merge: Choose File › Open… or File › Import for a .pzfx or .prism file, or File › Merge Project… to add sheets into an open project.
  2. Review warnings and snapshots: Unsupported items appear in Import Warnings. On read-only .prism snapshots, click Re-run as a CurveBook analysis… to compute fresh results.
  3. Export tables: Choose File › Export › CSV Table… for one table or Export All Data Tables… for a folder. Use File › Export › .pzfx file… to export data tables and info sheets.

Command line

Convert and export from the command line

Every download includes curvebook-cli beside the desktop app. Open a terminal in the folder with your file.

1. List the tables in a file

curvebook-cli info experiment.pzfx

Prints each table's ID, type, title, size, and any import warnings.

2. Export a table to CSV

curvebook-cli convert experiment.pzfx experiment.csv

Exports the first table. Select another table by title or ID:

curvebook-cli convert experiment.pzfx groups.csv --sheet "Groups"

Replicates stay side by side, and excluded values keep a trailing * (such as 55*). Use a .tsv filename for tab-separated output.

3. Convert the whole file to a CurveBook project

curvebook-cli convert experiment.pzfx experiment.curvebook

Keeps every table together for analyses, fits, and graphs. The same commands work on .prism files.

4. Export tables and info sheets to .pzfx

curvebook-cli convert experiment.curvebook export.pzfx

Writes a data-only .pzfx copy without modifying your project, and lists dropped items. See the CLI reference for all options, or MCP setup for AI assistants.

Good to know

Limits and privacy

  • Local only: Files stay on your computer with zero telemetry or network calls (Privacy Policy).
  • Size limits: Oversized files are refused cleanly rather than read partially. See exact caps in the files reference.
  • Problems: Check known issues or open a bug on GitHub Issues (share only data that can be public).
