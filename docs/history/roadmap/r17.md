### R17.1 Direct `.xlsx` import, OS drag-and-drop, and messy spreadsheet clipboard paste
Owner: open · Status: done (`394ee32` / `ec099b6`; hosted CI folded into [`R14.1`](../../ROADMAP.md#r141-beta-release-pipeline)) · Was: post-Beta prioritization 2026-11-23 · Depends on: **Beta** release · Gate: post-Beta · Est. note: 12–20 h

Most bench scientists store raw data in Excel or Google Sheets. Requiring manual CSV export and fighting locale decimal commas or multi-row headers on every import creates avoidable Day-1 friction.

- [x] Add pure-Rust `.xlsx` workbook import registered through `FormatRegistry` (`crates/format/src/xlsx.rs` using existing `crate::zip`, `quick-xml`, and `flate2` with zero new dependencies and zero telemetry: `cargo xtask licenses`, `cargo deny check licenses`, `cargo xtask telemetry`), exposing `table.importXlsx` and multi-sheet selection in the GUI Import Wizard (`crates/ui-egui/src/egui_shell/import_wizard.rs`), CLI (`info --list-sheets`, `convert --xlsx-sheets`), and MCP (`open_file`, `table_import_xlsx`). *(Implemented in `394ee32` and integrated on `feature/R17-integration`; verified by `r17_1_xlsx_and_csv`, `r17_1_import_xlsx_and_paste`, `r17_1_mcp_xlsx`, `r17_1_cli_xlsx`, and `r17_1_xlsx_and_paste`.)*
- [x] Support OS file drag-and-drop onto the desktop window (`apps/curvebook/src/{gui_window,desktop_host}.rs`) for `.curvebook`, `.cbtemplate`, `.prism`, `.pzfx`, `.csv`/`.tsv`, and `.xlsx` files with hover drop-zone overlay and status banner toast. *(Implemented in `394ee32` and integrated on `feature/R17-integration`; verified by `r17_1_dnd_and_paste`, `audit_r2_desktop_host`, and `r10_command_routing`.)*
- [x] Harden delimited and clipboard paste for real-world Excel/Sheets exports (`crates/doc/src/cell.rs`, `crates/format/src/csv.rs`, `crates/transform/src/import.rs`, `crates/tools/src/grid.rs`): locale decimal commas (`1,23`) vs. thousands separators, UTF-8/UTF-16 LE/BE BOMs, merged/multi-row headers, ragged rows, and quoted newlines, backed by unit and `EguiHumanPathDriver` regression tests (`r17_1_xlsx_and_paste`, `audit_p8_sec19`).
- [x] Verify locally: `cargo xtask ci` and `cargo xtask wasm` pass on the integrated `feature/R17-integration` tree. *(Hosted CI on `main` is gated centrally in [`R14.1`](../../ROADMAP.md#r141-beta-release-pipeline).)*
- [x] Follow-up (`bugfix/R17.1-drop-import-prompt`): dropping a `.prism`, `.pzfx`, or `.xlsx` file onto a window whose project has sheets or unsaved changes opens the same replace-or-merge import prompt as File › Import (shared `open_import_mode_prompt_if_needed` in `apps/curvebook/src/desktop_host.rs`) instead of silently replacing the open project and its undo history; empty-window drops, `.curvebook` drops, CSV/TSV drops, and File › Open are unchanged. *(Harness evidence only, not human-path evidence: `r17_1_drop_import_prompt` and `desktop_host_loop::file_dropped_pzfx_and_zip_archive_open_cleanly`.)*

### R17.5 Real-world legacy project import hardening
Owner: open · Status: done (`4d723c3`; follow-on corpus hardening & conformance completed in [`R22`](r22.md#r22-external-scientific-file-compatibility--project-merging-beta-gate)) · Was: post-Beta prioritization 2026-11-23 · Depends on: none · Gate: post-Beta · Est. note: 0 h remaining

Opening existing lab files cleanly is a primary adoption path. Real-world `.pzfx` and `.prism` files encounter older schema dialects, unusual subcolumn encodings, exclusions, and edge cases that synthetic clean-room fixtures do not cover. On 2026-11-26 the third-party `.pzfx`/`.prism` corpus harness, real-file defect fixes, schema `v9` interop extensions, and `.pzfx`/`.prism` conformance gates were promoted to Beta blockers and completed under [`R22`](r22.md#r22-external-scientific-file-compatibility--project-merging-beta-gate). *(The point-in-time `docs/evidence/r17-5-legacy-import-hardening.md` log was retired after `R22` landed and remains in git history at `84ed032`; live format notes live in [`interop-format-notes.md`](../../evidence/interop-format-notes.md).)*

- [x] Audit and harden `.pzfx` XML and `.prism` ZIP container dialect handling across `crates/format/src/error.rs`, `crates/format/src/xml.rs`, `crates/format/src/pzfx/`, and the `.prism` archive module in `crates/format` (`EVFormat` vs `YFormat` separation, `YFormat="SDN"`, `PlusMinus` & swapped `UpperLower` limits, 2-subcolumn missing-`N` diagnostics, `XFormat` text/date/sequence/err handling, `<RowTitlesColumn><Title>` & `Title="..."` attribute fallbacks, direct `<d>` children, column/subcolumn exclusions, decimal commas/thousands/Unicode minus, `<HugeTableSequence>`, root/info/table notes, schema version & unwrapped unsupported-section checks, 28 scientific/XHTML XML entities, nested single-root `.prism` ZIPs, case-insensitive lookup, external `document.json`, explicit non-table JSON routing, SQLite detection, relative `csv_path` & directory sidecars, `clamp_title`) with structured `ImportWarningKind` variants and consumer propagation (`finish_project_import_report` in `crates/engine/src/cmd/table/import.rs`, `cmd_convert.rs` stderr/JSON warnings). *(Implemented in `4d723c3` and integrated on `feature/R17-integration`.)*
- [x] Add minimized clean-room regression fixtures in `crates/format/tests/format_suite/r17_5_legacy_import_hardening.rs`, `crates/engine/tests/core_suite/r17_5_import_warning_propagation.rs`, and `apps/curvebook-cli/tests/cli_suite/r17_5_cli_warnings.rs` (`cargo xtask ci` and `cargo xtask cleanroom` pass).

### R17.6 Report `.xlsx` formulas without stored results
Owner: open · Status: done (`ead3025`; hosted CI folded into [`R14.1`](../../ROADMAP.md#r141-beta-release-pipeline)) · Was: reporting-accuracy review 2026-11-24 · Depends on: none · Gate: post-Beta · Est. note: 2–4 h

A formula cell saved without a stored result (common in workbooks written by scripts) was imported as an empty cell, while the worksheet warning said that cached values were imported. A silently empty cell changes `n` in every analysis that reads it.

- [x] Count formula cells without a stored result separately and report them as a `MissingCachedValue` import warning naming the worksheet, the count, up to five example coordinates, and a prompt to recalculate and save the workbook before importing again; the existing warning now counts only formulas whose stored results were imported.
- [x] Test a worksheet with both cached and uncached (plain and shared) formulas in `crates/format/tests/format_suite/` (`r17_6_xlsx_uncached_formulas`).

### R17.7 Multi-block tabular import, standalone AUC analysis, and composable microplate mapping
Owner: open · Status: done (`2132c92`; hosted CI folded into [`R14.1`](../../ROADMAP.md#r141-beta-release-pipeline), interactive manual QA folded into [`R10.13`](../../ROADMAP.md#r1013-human-operable-50-workflow-acceptance--manual-qa)) · Was: kinetic microplate workflow review 2026-11-25 · Depends on: none · Gate: post-Beta · Est. note: 18–28 h

Real-world dual-emission kinetic microplate experiments export preamble-prefixed multi-channel sheets (`.xlsx` and `.csv`) and merged-cell `8×12`/`16×24` layout grids that need clean ingestion, per-well kinetic integration, and traceable plate-to-table reshaping without vendor-specific parsers or brittle heuristics. This item bundled two sequential vertical slices (cross-referencing [`R19.2`](r19.md#r192-high-usage-statistical-analyses--graph-families) Tier 1 AUC):

- [x] **Slice 1 (core headless vertical slice + schema `v7 → v8`):** Bumped `CURRENT_SCHEMA_VERSION` to `8` (`migrate_v7_to_v8` + streaming `DataSheetVisitor` and `.cbtemplate` stripping for `plate_well_origins`); added versioned single-extension `.cbplate` plate-layout persistence (`format_version = 1`, atomic writes, `docs/schemas/plate-map.schema.json`); added explicit `.xlsx`/`.csv` range/windowing, exact OOXML `fill_merged_cells`, `row_match` (`ImportFilterSpec`), deterministic `split_by_column`, and shared `InfoSheet` preamble extraction; wired standalone `AnalysisKind::AreaUnderCurve` (`R19.2` Tier 1: partial `[x_min, x_max]` linear interpolation, exact Bailer `NetAreaSe` weights gated by `independent_time_points`, `AucBaseline::Fixed | FirstPoint`, two-sided/one-sided effective-window checks, unavailable row retention, and R/SciPy `D1` oracles); extended `table.importPlateMap` to consume `require_analyzable_data_sheet` (`UpToDate` guard + `value_column`), strict `8×12`/`16×24` `label_grid`/`x_grid`/`layout_sheet_id`, and maintained `plate_well_origins` traceability; regenerated schemas and `docs/commands.md`. *(Verified in `r17_7_import_and_schema_v8`, `r17_7_end_to_end`, and `curvebook-transform` AUC/plate suites.)*
- [x] **Slice 2 (kinetic reducers, CLI/MCP forwarding, interactive GUI, docs & CI):** Added lightweight kinetic reducers (`row_index`, `x_window_mean`, `min`, `max`) to `table.importPlateMap`; forwarded new `.xlsx` options in CLI `convert` and MCP; added explicit `ImportWizard` controls (reusing `extract_info_metadata`), `transform.auc` modal, interactive `8×12`/`16×24` `ImportReshape` grid with dilution-series fill and `.cbplate` Save/Load, and `Source well` cell tooltips with 5-stage `WorkflowRun` evidence; updated reference docs (`tables.md`, `analyses.md`, `qol.md`, `file-formats.md`), 16-locale `catalog.tsv`, registries, and passed all `xtask` CI gates. *(Verified in `r17_7_end_to_end`, `r17_1_cli_xlsx`, `r17_1_mcp_xlsx`, `r17_7_plate_auc_gui`, and `xtask` gates.)*
