### R23.1 Calculated Variables formula engine parity, bug fixes & window semantics
Owner: open · Status: done (`84ed032` + Formula Studio GUI completion, 2026-11-27) · Was: reference-coverage audit 2026-11-26 (Cluster 5) · Depends on: none · Gate: optional before Beta (non-blocking) · Est. note: 14–22 h

- [x] Fixed formula syntax and semantic bugs in `crates/transform/src/formula/{parser.rs,eval.rs,dag.rs}`: distinguished numeric-only `COUNT` from non-empty `COUNTA` (matching [`docs/reference/tables.md`](../../reference/tables.md)); supported 1-argument `MIN(var)` / `MAX(var)` column and window aggregations alongside `min_col`/`max_col`; accepted unparenthesized window clauses (`OVER Col`, `ROWS <n> PRECEDING <m> FOLLOWING`); aligned `ORDER BY` without explicit `ROWS` to full-partition evaluation (keeping explicit `ROWS`/`RANGE` cumulative frames intact); emitted blank cells on blank partition keys and filtered-out `WHERE` + `ROWS` rows; documented explicit base-10/truncation/case-insensitive-comparison compatibility rules; and added `table.unlinkCalculatedVariable` (freeze calculated column to static entered values in one undoable step). *(Headless engine & transform landed in `84ed032`.)*
- [x] Added the 23 non-deferred missing formula functions to `crates/transform/src/formula/eval.rs` backed by `curvebook-math`: `fact(n)`, infix/function `mod(x, y)`, `perc(x)`, `null` literal, `pi([n])`, `asinh`/`arcsinh`, `acosh`/`arccosh`, `atanh`/`arctanh`, `rad(deg)`, `deg(rad)`, seeded `gauss(mean, sd)` and `rnd(lo, hi)`, special functions (`gamma`, `gammaln`, `igamma`, `igammac`, `psi`/`digamma`, `beta`, `ibeta`, `besselj`/`bessely`/`besseli`/`besselk`, `hypgeometricm`/`hypgeometricu`/`hypgeometricf`), and `concatenate(...)` (keeping the 16 deferred `R9.13` probability distribution calculators parked separately). *(Landed in `84ed032`.)*
- [x] Added `D1` numerical/edge-case tests in `crates/transform/tests/`, engine command tests, and updated [`data-tables-and-transforms.md`](../../implementation/data-tables-and-transforms.md) / [`docs/reference/tables.md`](../../reference/tables.md) documentation. *(Landed in `84ed032`.)*
- [x] Completed desktop Formula Studio GUI controls (`crates/ui-egui/src/egui_shell/trailing_studio/mv_formula.rs`, `crates/ui-egui/src/egui_shell/data_grid/{mv_roles,multi_archetype}.rs`): added the localized **Unlink Formula** (`inspector.mv.unlink_formula`) secondary action dispatching `table.unlinkCalculatedVariable` (plus calculated-column header/cell context-menu entries, disabled when frozen) with clean `mv_formula_draft` resynchronization across unlink and undo; expanded `STUDIO_FORMULA_FUNCS` to all 66 non-deferred functions inside a bounded scrollable reference pane; added 16-locale strings in `crates/ui-egui/locales/catalog.tsv`; and added `EguiHumanPathDriver` regression coverage in `crates/ui-egui/tests/r15_shell_suite/r15_3_studio_footer.rs`. *(Done 2026-11-27.)*
