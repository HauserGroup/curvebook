### R12.5 Getting started, files, settings and support
Owner: open · Status: done · Was: split from `R12.1` 2026-11-18 · Est. note: 20–32 h · Depends on: `R12.1` (generator), [`R14.1`](../../ROADMAP.md#r141-beta-release-pipeline) (final installers and download set) · Gate: **Beta** (required)

This item is the only home for install, download, and verification steps and for the known-issues list. The README (`R0.27`), the release-notes template, `releasing.md`, and `packaging/*/INSTALLATION.md` link here instead of repeating them.

- [x] **Get started — install page:** system requirements; installing each Beta download from the `R14.1` set, with a "which file do I need?" table and the `curvebook-<version>-<os>-<arch>.<ext>` names; verifying checksums and Sigstore attestations (the former standalone verification page was merged in by `R0.31`); the signed macOS `.dmg` and how to put the bundled `curvebook-cli` on `PATH`; the unsigned Windows `.msi` (SmartScreen **More info → Run anyway**; Smart App Control may block it; the Store package as an alternative once `R8.9` lands); fonts (system discovery and `CURVEBOOK_FONTS_DIR`); updating without an auto-updater; uninstalling. *(Done 2026-11-18 in [`get-started.md`](../../reference/get-started.md).)*
- [x] **Desktop GUI getting started:** a short page covering install, the Welcome dialog, entering data, a first analysis and graph, saving, and exporting, with original screenshots attributed in `ASSETS.md` (unlocked by the `R10.13` desktop walkthrough and `R10.23` Beta gates). The full step-by-step guides remain `R12.2`, after Beta, and the full **Using the app** reference remains `R12.7`. *(Done 2026-11-18 in [`desktop-gui.md`](../../reference/desktop-gui.md), citing `HumanPathDriver`-verified `R10` & `R10.23` flows and `ASSETS.md`-attributed screenshots.)*
- [x] **Files, import and export:** the `.curvebook` project and `.curvebook.d/` unpacked forms, templates, what a saved project contains (sharing a workspace), format versions and the refusal to overwrite newer files, autosave and crash recovery, every import and export format with its options and limits (from the format descriptors), and CSV/TSV parsing rules. Name interchange formats only as the brand policy allows. *(Done 2026-11-18 in [`files.md`](../../reference/files.md).)*
- [x] **Settings and languages:** every preference key (from `preferences.schema.json`), keyboard shortcut customisation, interface languages, and locale-dependent number and date formatting. *(Done 2026-11-18 in [`settings.md`](../../reference/settings.md).)*
- [x] **Privacy, licences and security:** zero telemetry and no network access, loopback-only sockets, what GitHub Pages logs, the dual licence, third-party attributions, the clean-room statement, and how to report a vulnerability ([`SECURITY.md`](../../../SECURITY.md)). *(Done 2026-11-18 in [`privacy-security.md`](../../reference/privacy-security.md).)*
- [x] **Troubleshooting and known issues:** install, fonts, MCP connection, file recovery, and error messages, plus the known issues and limits of each release (carried forward from [`alpha-known-issues.md`](../release/alpha-known-issues.md)) and links to the release notes. The Beta known issues replace the Alpha list: drop the "GUI is pre-alpha" warning; present the desktop GUI as a supported way to use CurveBook; list the desktop limits actually found in `R10.13` and `R10.24`; note the machine-drafted draft translations (`R10.23`); describe the FreeBSD desktop app as a preview; note that the browser app is deferred to `1.0` (`R11`) and that Windows `x86` is no longer shipped. *(from R0.27, R0.28 — done 2026-11-18 in [`troubleshooting.md`](../../reference/troubleshooting.md).)*
