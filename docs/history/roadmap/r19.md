### R19.6 Fix Hougaard skewness sign mismatch and false zero for uncomputed entries
Owner: open · Status: done (`5d29a24` / `78c9f91` / `e7cd065`) · Was: scientific results review 2026-11-25 (immediate standalone bugfix) · Depends on: none · Gate: post-Beta · Est. note: 2–4 h

Two correctness bugs undermined the Hougaard skewness column on nonlinear regression fits: (1) `compute_hougaard_skewness_into` (`crates/fit/src/diagnostics.rs`) returned signed $g_1$ and `crates/fit/src/result.rs` printed the signed value under `"Hougaard |g1|"` while the checklist took `.abs()`; and (2) `fit_plot_function_only`, `compute_fit_hougaard`, and `compute_hougaard_skewness_into` returned `0.0` instead of `f64::NAN` whenever uncomputed (`!enabled`, `k_free > 10`, `cov_unscaled.is_none()`, `sqrt_w.is_none()`, `df == 0`, plot-function-only, or evaluation failure). *(Detailed spec originally in `docs/planning/gui-improvements.md` §3, retired after `e7cd065` and preserved in git history.)*

- [x] **Return `f64::NAN` whenever Hougaard skewness is uncomputed (`crates/fit/src/diagnostics.rs`, `crates/fit/src/solver/fit.rs`):** Replaced remaining `0.0` fallback fills in `fit_plot_function_only`, `compute_fit_hougaard`, and `compute_hougaard_skewness_into` with `f64::NAN` (and gated `hougaard_enabled` on non-failed `FitStatus`) so uncomputed cells render blank / `"—"`, never `0`. *(Done in `5d29a24`.)*
- [x] **Make magnitude consistent with `"Hougaard |g1|"` (`crates/fit/src/result.rs`, `crates/fit/src/solver/results.rs`):** Preserved signed $g_1$ in `compute_hougaard_skewness_into` / `FittedParameterSummary::hougaard_g1` (updating doc comments) and applied `.abs()` consistently across all 4 `"Hougaard |g1|"` table cell sites in `result.rs`. *(Done in `5d29a24`.)*
- [x] **Regression tests (`crates/fit/tests/core_suite/d1_fit_uncertainty.rs`):** Added unit and result-sheet tests (`mod hougaard_skewness_uncertainty`, folded into `core_suite` in `78c9f91`) asserting `compute_hougaard=false`, `fit_plot_function_only`, `df == 0`, `cov.ambiguous`, `k_free > 10`, evaluation failure, and non-positive diagonal covariance emit `f64::NAN` / blank cells (never `0`), and negative signed $g_1$ renders as positive `|g1|` matching checklist evaluation (`cargo test -p curvebook-fit` and `clippy --all-targets -- -D warnings` clean). *(Done in `5d29a24` / `78c9f91`.)*

### R19.7 Nonlinear fit report clarity, per-dataset goodness of fit & null-model diagnostics
Owner: open · Status: done (`94e4fad` / `d99001d` / `e7cd065`) · Was: scientific results review 2026-11-25 · Depends on: none (coordinates with [`R19.1`](../../ROADMAP.md#r191-descriptive-statistics-resultui-parity--nonlinear-identifiability-formatting); banner UI in [`R20.6`](r20.md#r206-consolidate-duplicate-nonlinear-fit-parameter-identifiability-warning-banners); CI cell formatting in [`R20.10`](r20.md#r2010-results-table-ci-first-column-sizing-borderless-underline-tabs-quiet-header-actions--explicit-ci-formatting)) · Gate: post-Beta · Est. note: 12–18 h

In multi-dataset nonlinear fits, `crates/fit/src/result.rs` previously emitted only a pooled global `Goodness of Fit` column and footnote even when datasets were fitted independently without shared parameters, and surfaced wild divergent solver iterates in primary cells without failing dataset lists or a flat-vs-partial horizontal-line null-model diagnostic. Updated with per-dataset GoF, safe `"Unstable"` masking with raw iterate metadata (`ResultSheet::cell_details`), failing-dataset summaries, `Y = Mean` comparison service, and the `CiBound::Unavailable` backend enum. *(Detailed spec originally in `docs/planning/gui-improvements.md` §4, retired after `e7cd065` and preserved in git history.)*

- [x] **Per-dataset `Goodness of Fit` columns & clean footnote (`crates/fit/src/{result.rs, solver/{results.rs, assembly.rs, datasets.rs, fit.rs}}`):** Populated per-dataset `df`, `weighted_ss`, `aic_c`, `bic`, residual diagnostic counts, and `is_independent_multi_dataset()`, emitting per-dataset GoF columns (`append_independent_nonlinear_gof_tab`) for independent fits while keeping a pooled column for shared/single-dataset fits, with Unicode `R² =`, consistent `"; "` separators, and `dataset_convergence_summary` (`"N of M converged; K ambiguous"`). *(Done in `94e4fad`.)*
- [x] **Safe default display for unstable/divergent estimates (`crates/doc/src/{result.rs, project.rs, schema.rs}`, `crates/fit/src/result.rs`, `docs/schemas/document.schema.json`):** Added `ResultCellDetail` / `ResultSheet::cell_details` and updated `should_mask_parameter_as_unstable` (`IdentifyUnstableParameters` / `None`) to mask `Unstable`, non-finite estimates, or singular `Ambiguous` parameters with `!se.is_finite()` as `"Unstable"` while keeping correlated finite-SE fits numeric (`~`) and retaining `raw_value` + diagnostic detail in `cell_details` and JSON outputs, alongside `CiBound::Unavailable` emission for `df == 0` / singular / Robust Cauchy entries. *(Done in `94e4fad` + `d99001d`.)*
- [x] **Failing dataset summary & horizontal-line (`Y = Mean`) null-model diagnostic (`crates/fit/src/solver/comparison.rs`, `crates/engine/src/services/fit_diagnostics.rs`):** Exposed `failing_datasets` in checklist and `collect_nonlinear_diagnostics` (`"Ambiguous / unbounded fits in N of M datasets (A, B, …)"`), and added diagnostics-only `compare_vs_horizontal_line`, `compare_nonlinear_analysis_vs_horizontal_line`, and `curvebook_engine::services::compare_result_vs_horizontal_line` classifying `"Not distinguishable from horizontal line (P = …, ΔAICc = …)"` vs. `"Incomplete / unbounded curve (plateau or EC50 outside tested range)"`. *(Done in `94e4fad`.)*
- [x] **Regression tests (`crates/fit/tests/core_suite/audit_solver_fixes.rs`, `crates/engine/tests/core_suite/services_and_declarative_patches.rs`):** Added multi-dataset tests (`mod fit_report_clarity_and_null_diag` and `r19_7_engine_*`, folded into `core_suite` in `78c9f91`) covering per-dataset vs. pooled GoF, footnote `R²` and convergence summaries, `"Unstable"` suppression + `cell_details` preservation, `CiBound::Unavailable` (`df == 0` / mixed / profile-likelihood), failing-dataset lists, and flat vs. partial-curve null-model classification (`curvebook-doc`/`fit`/`engine` suites and `human_wf_suite` 76/76 passing). *(Done in `94e4fad` + `d99001d` / `78c9f91`.)*
