### R20.2 Theme module, opaque surface tiers, standard control kit & numeral alignment
Owner: open · Status: done · Was: visual & HIG design review 2026-11-24 · Depends on: [`R20.1`](../../ROADMAP.md#r201-visual-design-system--layout-specification-overhaul) · Gate: none (non-blocking for Beta) · Est. note: 8–14 h

- [x] Consolidate surface and control tokens inside `crates/ui-egui/src/theme.rs` and `crates/ui-egui/src/egui_shell/{mod,ui_kit,widgets}.rs`: add `surface_recessed` and `selection_unemphasized_bg`, separate hairline `divider` from `input_border`, tighten the accent budget, and ship borderless ghost action, equal-width segmented control, underline panel tab, and checkbox/switch primitives.
- [x] Start the gradual migration onto the `4`-point spacing rhythm (`4 / 8 / 12 / 16 / 24 pt` + `2 pt` micro-inset), validating provisional `6 pt` retirement across docks, forms, and dialogs at default and increased text scales (`ui_scale > 1.0`).
- [x] Retire the `12.5 pt` numeral size in favor of `13 pt` aligned grid numerals backed by a runtime ASCII `'0'..='9'` advance-width check on the resolved primary sans face (falling back to a uniform-digit system sans or cap-height-matched monospace strictly for aligned numeric columns).
- [x] Add unit and specimen verification (`cargo xtask screenshots --check`) confirming WCAG 2.2 SC 1.4.11 (Level AA) contrast (`>= 3:1`) for all interactive control and state cues across `Light`, `Dark`, and `HighContrast`.

### R20.3 Three-way split targeting, unified split `DataGrid`, single-owner navigation & shared panel headers
Owner: open · Status: done · Was: visual & HIG design review 2026-11-24 · Depends on: [`R20.2`](#r202-theme-module-opaque-surface-tiers-standard-control-kit--numeral-alignment) · Gate: none (non-blocking for Beta) · Est. note: 16–26 h

- [x] Implement the three-way split-view targeting contract: materialize explicit `primary_sheet_id` and `secondary_sheet_id` in `SplitWorkspaceState`; add ephemeral `inspector_target_sheet_id` and `inspector_pinned` (auto-pinned to the graph on the `Data + Graph` split preset; auto-unpinned when the pinned sheet leaves the split pair, is deleted via `sheet.delete`, or Split Comparison closes); route split-pane activation and compact pane flips through non-mutating `sheet.select` with `mode: "family"` (preserving `family_anchor_sheet_id` without pushing undo entries, dirtying the session, or writing to `ops.journal`); keep `doc.active_sheet_id` and `inspector_target_sheet_id`/`inspector_pinned` attached to their sheets across `Swap`.
- [x] Audit all Trailing Studio Inspector and split `DataGrid` UI call sites in `crates/ui-egui` so every engine mutation (`graph.setSpec`, `graph.setSeries`, `graph.setAxes`, `table.setCell`, etc.) passes its explicit target `sheet_id` (`inspector_target_sheet_id` or the pane's materialized `SheetId`), never reading `doc.active_sheet_id` implicitly.
- [x] Parameterize the virtualized `DataGrid` renderer (`crates/ui-egui/src/egui_shell/data_grid/`) by explicit `sheet_id` with per-pane scroll/selection state, delete `render_split_non_column_preview` and `render_split_column_sheet_preview`, and unify flat contiguous hairline cells, neutral column headers, and uppercase archetype badges (`XY`) across single and split views.
- [x] Remove duplicate Tier 2 `sheet.tab.*` tabs and Bottom Footer 5-category jump pills, add the collapsed-Navigator active-sheet footer switcher, and migrate dependent test suites and classifiers (`apps/curvebook/tests/desktop_suite/r15_3_menus_chrome.rs`, `crates/ui-egui/tests/r15_2_anova_and_1m_bench.rs`, `crates/ui-egui/tests/r15_shell_suite/r15_3_top_chrome.rs`, `crates/ui-egui/tests/r15_shell_suite/r15_4_r10_23_egui_gaps.rs`, and `crates/ui-egui/src/egui_shell/{top_chrome,inspect_bridge,driver}.rs`) onto the surviving Navigator and Footer navigation paths.
- [x] Align shared panel headers (`32 pt` provisional target) across Navigator, Center Split panes (dropping `Primary`/`Secondary` labels and the duplicate sub-bar, replacing the permanent blue pane cage with a `2 pt` active header bar), and Trailing Studio; implement the `760 pt` preferred / `720 pt` hard horizontal floor usable-width dock solver, `40/60` `Data + Graph` default ratio, vertical split below `720 pt`, and `< 720 × 520 pt` (`640 × 420 pt` / high `ui_scale`) single-pane header flip fallback; add `panel_header_baseline_parity`, `split_targeting_parity`, and `split_unified_datagrid_parity` verification gates.
