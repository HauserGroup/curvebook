# Alpha Branding, Clean-Room & Asset-Provenance Clearance (`R0.21` / `R10.14`)

> **Milestone:** [`R0.21`](../roadmap/r0.md#r021-strict-alpha-branding-and-asset-provenance-gate) (`done`) & [`R10.14`](../roadmap/r10.md#r1014-external-branding-exclusion-sweep--gate) (checkbox 2 `done`) · **Status:** Enforced by `cargo xtask brands`, `cargo xtask cleanroom`, `cargo xtask assets`, and `xtask/tests/r021_strict_alpha_branding.rs`.

CurveBook maintains original product identity (`CurveBook`, App ID `org.curvebook.CurveBook`) across source code, file paths, UI/window chrome, localization, command catalogs, MCP tools/resources/prompts, documentation, exports, packaging manifests, and visual assets, without copying third-party proprietary materials, icons, screenshots, sample files, or marketing wording.

## 1. Enforced Surfaces & Automated Gate Architecture

The release gates in [`xtask/src/brands.rs`](../../../xtask/src/brands.rs), [`xtask/src/cleanroom.rs`](../../../xtask/src/cleanroom.rs), and [`xtask/src/assets.rs`](../../../xtask/src/assets.rs) perform zero-waiver automated verification across the entire workspace and assembled bundle surfaces:

1. **Tracked source, identifiers, comments, literals, paths & manifests (`cargo xtask brands`):**
   - Scans all tracked files and relative paths (`720` tracked entries) without blanket test-directory, `#[cfg(test)]`, `tests/`, `crates/testkit/`, `xtask/`, or documentation (`docs/*.md`, root `.md`, CSS/JSON/YAML/shell/WiX/plist) exclusions.
   - Splits ASCII alphanumeric and snake/kebab runs at CamelCase, acronym, digit, `-`, and `_` boundaries so compound identifiers (`*Style`, `*_theme`, `like_*`, uppercase/lowercase/mixed variants) are detected uniformly across all `14` tracked statistical software vendor/product tokens in `BRANDS` and `15` retired suite tokens in `SUITE_BRANDS`.
   - Removes generic waiver markers from production, test, packaging, SVG, HTML, TOML, and documentation files; the sole `ALLOW_MARKER` exemption is the non-affiliation disclaimer line in [`README.md`](../../../README.md).
2. **Clean-room copyright & fixture scanner (`cargo xtask cleanroom`):**
   - Inspects UTF-8, UTF-16 LE/BE (with and without BOM), nested ZIP/`.curvebook`/`.cbtemplate`/`.prism`/`.pzf` archives, XML parser fixtures, HTML, and bundled distribution trees via [`scan_dist_artefacts`](../../../xtask/src/cleanroom.rs) for proprietary copyright notices, "Created by / Generated by / Exported from" creator tags, vendor XML root tags, and accidental committed reference-frame folders.
3. **Assembled launch artefact & web/bundle scanner (`brands::scan_dist_artefacts_with_stats`, `cleanroom::scan_dist_artefacts_with_stats`):**
   - Automatically scans [`packaging/web/`](../../../packaging/web) and any assembled `dist/` directory (recursing without symlink loops across `.app` bundles, `Info.plist`, `.desktop`, `.mime.xml`, HTML/CSS/JS, `THIRD-PARTY-LICENSES.html`, manifests, PDFs, SVGs, PNG/ICO/ICNS/GIF metadata chunks, and nested ZIP archives, reporting explicit `dist/` file and archive-entry counts), and rejects any bundled `docs/audit/` or local reference-frame tree.
4. **Live rendered UI & 16-locale `LayoutTree` sweep (`check_ui_surfaces`, `check_live_layout_tree_surfaces`):**
   - Sweeps all `16` `i18n::LOCALES` (`12,016` catalog entries + display names), all menu bar & toolbar tooltips, `engine_cmd_registry()` schemas/descriptions, `UI_COMMANDS`, `ANALYSIS_CATALOG`, `SAMPLE_FIXTURES`, and live rendered `build_workspace_layout_tree` frames (`LayoutTextRun` + `WidgetNode.a11y`) across all `5` sheet kinds (`DataSheet`, `InfoSheet`, populated `ResultSheet`, `GraphSheet`, `LayoutSheet`), all `4` `WelcomeMode` screens, all `7` `ActiveInspector` tabs, all `26` `ActiveDialog` states (including `CommandPalette` default and filtered states), all open dropdown menus, narrow-viewport toolbar overflow, Split workspace, and Portfolio Gallery.
   - Verifies rendered SVG (`render_svg`), vector PDF (`render_pdf`), `ClipboardBundle` SVG/PDF/HTML, `.curvebook` / `.cbtemplate` ZIP `manifest.json`, and desktop window titles.
5. **Live MCP JSON-RPC 2.0 transport & surface verification (`check_mcp_surfaces`, `check_mcp_rpc_response`):**
   - Instantiates in-process `curvebook-mcp` sessions in both default headless mode and strict `--gui-only` mode (`McpServerState` + `BrandsGuiSessionHost`) backed by a populated 5-sheet `ProjectDocument` (`DataSheet`, `InfoSheet`, recalculated `OneWayAnova` `ResultSheet`, `GraphSheet`, and `LayoutSheet`) and drives JSON-RPC 2.0 requests via `dispatch_json_value`:
     - `initialize` (`serverInfo.name = "curvebook"`, `SERVER_INSTRUCTIONS`, and `GUI_ONLY_SERVER_INSTRUCTIONS`)
     - `tools/list` (`10` default core tools, all `115` tools after `list_toolsets` + `enable_toolset` across all `9` `CommandGroup`s and `gui`, plus the strict `8`-tool `--gui-only` surface) and `command_list` (`97` engine + `45` UI commands)
     - `resources/list` and `resources/read` across every `sheet://<id>` and `result://<id>` URI (plus `--gui-only` structured error payloads)
     - `prompts/list` and `prompts/get` across every registered workflow prompt and parameter branch in both headless and `--gui-only` modes
     - `tools/call` replies for `doc_inspect` (overview + all `5` sheet kinds with `include_cells: true`), `render_preview` (`graph-1` and `layout-1`, decoding inline Base64 PNG payloads to inspect PNG metadata chunks), inline `export` (`svg`), `ui_inspect`, and `ui_screenshot`.

## 2. Narrow Format-Compatibility Boundaries & Provenance Exceptions

Every exception permitted by the gate is structural, verified by both positive and negative regression cases in [`xtask/tests/r021_strict_alpha_branding.rs`](../../../xtask/tests/r021_strict_alpha_branding.rs) and `xtask/src/brands.rs`:

- **`.pzfx` / `.prism` file interchange boundary:**
  - *Allowed:* File extensions and filter lists (`.prism`, `*.prism`, `.pzfx`), MIME type identifiers in `.mime.xml`/`.desktop` `MimeType=`, macOS `CFBundleTypeExtensions` array extension entry in `Info.plist.in`, canonical format module/registry/command identifiers (`crates/format/src/pzfx.rs`, `crates/format/src/registry.rs`, `table.importPrism`), XML root tag/attribute boundaries in `.pzfx` parsers and parser tests, and `.prism` archive diagnostics referencing container chunks.
  - *Rejected:* Vendor or third-party product names, URLs, product titles, marketing/help prose, desktop `Keywords=`, packaging display labels (`CFBundleTypeName` / MIME `<comment>`), or non-format CamelCase/snake_case UI/style identifiers anywhere in source, UI, docs, or release bundles.
- **Language & compiler precision allowances:**
  - Lowercase Italian translation noun for "statistics" is permitted strictly inside `locale == "it"` localization entries / rendered Italian UI frames and the peer-reviewed citation in [`crates/stats/src/pvalue_stack.rs`](../../../crates/stats/src/pvalue_stack.rs); English/other locales, capitalized occurrences, identifiers, manifests, and exports fail.
  - Bytecode compiler jump-offset variable is permitted strictly as a non-string VM identifier inside [`crates/fit/src/dsl.rs`](../../../crates/fit/src/dsl.rs); external software tokens remain blocked everywhere else.
- **Historical & policy scopes:**
  - Read-only historical Wave 1–2 audit archives under `docs/audit/**` are excluded from repository scanning while remaining forbidden inside any assembled `dist/` bundle.
  - [`AGENTS.md`](../../../AGENTS.md#limited-local-jpg-reference-policy) retains the exact scope definition naming the gitignored local reference folder (`cargo xtask cleanroom` and `cargo xtask assets` forbid committing any files under that path).
  - Test negative-assertion loops (`for forbidden in [...]`) are narrowly exempted only on explicit `tests/` guard assertion lines while all other test literals, identifiers, and comments remain strictly scanned.
