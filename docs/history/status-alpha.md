**Milestone policy updated 2026-11-16:** Alpha means **full MCP functionality for the currently implemented engine scope, with known bugs acceptable**, launched under the **CurveBook** name. This covers actual MCP command discovery/execution, data and analysis/fitting workflows, graph/layout previews and exports, project persistence, batches, resources/prompts, and structured failures in the documented modes. Deferred features are outside the current Alpha scope. Known bugs and audit findings must remain documented; Alpha does not promise production reliability, stable interfaces, or full audit closure, and does not waive the project's scientific or engineering rules.
