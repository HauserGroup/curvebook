# Platform, GPU & Print Hardware Parity

> **Scope & Environment Note:** Cross-platform installer manifests (`packaging/`), `--control <port>` / `--headless-once` / `--portable-dir` / `--ttf-font` / `--rulers` binary entrypoints (`apps/lumencraft`), WebAssembly shell init (`apps/lumencraft-web`), CPU rasterizer (`lumencraft-render`), multi-flavor clipboard payload builder (`ClipboardBundle`), subprocess OS pasteboard/print adapters (`write_os_pasteboard`, `read_os_pasteboard`, `submit_os_print_job`), inertial pan/zoom state (`PanZoomInertiaState`), external font discovery (`LUMENCRAFT_FONTS_DIR` / `font_diagnostics`), and physical-scale PDF print spool builder (`PrintJobSpec::spool_pdf`) are implemented and verified headlessly. Native OS GPU GUI windowing (`eframe`/`egui`/`wgpu`), live `wasm32` browser runtime, rich OS vector PDF/EMF clipboard IPC, and interactive OS print dialogs remain unchecked (`[ ]`) pending native GUI/CI runner validation (`G6`, `G11`, `M7`).

## Operating Systems & Targets
- [ ] macOS 11+ universal (`aarch64-apple-darwin`, `x86_64-apple-darwin`) native menu bar, file associations, and Retina HiDPI scaling *(`packaging/macos/` bundle generator & `lumencraft` entrypoint (`--in-window-menus`, `--control`) verified; live Cocoa/`eframe` window loop pending in `G6`/`M7`)*
- [ ] Windows 10/11 (`x86_64`, `i686`, `aarch64`) static-CRT builds, dual-scope WiX v5 MSI, and `portable.txt` portable mode *(`packaging/windows/` MSI manifests & `--portable-dir` / `portable.txt` discovery verified; Windows native runner execution pending in `G6`/`M7`)*
- [ ] Linux (`x86_64`, `aarch64`, `riscv64`) Wayland + X11 windowing, XDG file-chooser portal, AppImage, `.deb`, `.rpm`, and sandboxed Flatpak *(`packaging/linux/` `nfpm`, AppImage, `.desktop`, metainfo, MIME, and Flatpak manifests present; live Wayland/X11 window runtime pending in `G6`/`M7`)*
- [ ] FreeBSD (`x86_64`, `aarch64`) native desktop & CLI tarball *(`packaging/freebsd/package.sh` present; FreeBSD runner execution pending in `M7`)*
- [ ] Browser WebAssembly (`wasm32-unknown-unknown` with `+simd128`) running offline-capable in Chrome, Firefox, Edge, and Safari *(`apps/lumencraft-web::init_web_app` tested natively on host; `cargo xtask wasm` skipped locally because `wasm32-unknown-unknown` sysroot is absent in offline workspace, enforced in CI & `G6`)*

## Rendering, Clipboard & Printing
- [ ] `wgpu` hardware-accelerated canvas rendering (Metal, Vulkan, DX12, WebGPU, WebGL2) + deterministic CPU fallback for headless CLI exports *(deterministic CPU software rasterizer `lumencraft-render` + UI software frame compositor `render_workspace_frame_png` verified; native GPU `eframe`/`wgpu` backend not bundled in offline `Cargo.lock`, queued in `G6`)*
- [ ] Smooth trackpad pinch-to-zoom and inertial pan on Graph and Layout sheets *(`PanZoomInertiaState` + `CanvasDialogState` zoom & `ui.zoom.fitSheet` verified in `lumencraft-tools` & `ui-egui`; live OS trackpad gesture stream pending in `G6`/`M7`)*
- [ ] Native vector clipboard copy (PDF pasteboard on macOS, EMF/SVG/HTML+PNG on Windows/Linux) for pasting editable figures directly into manuscripts and slide decks *(multi-flavor `ClipboardBundle` emitting `PDF`, `SVG`, `HTML`, high-DPI `PNG`, and locale-aware TSV plus subprocess text adapters `write_os_pasteboard` / `read_os_pasteboard` (`pbcopy`/`wl-copy`/`xclip`/`clip`) verified; rich native vector PDF/EMF OS pasteboard IPC queued in `G11`)*
- [ ] Native OS print pipeline (CUPS on macOS/Linux/FreeBSD, Print Ticket / PDF vector spooling on Windows) *(physical `100%`-scale multi-page PDF print spooling with optional crop/bleed marks via `PrintJobSpec::spool_pdf` plus `submit_os_print_job` (`lp`/`lpr`) verified; interactive OS print dialogs & Win32 Print Ticket queued in `G11`)*
