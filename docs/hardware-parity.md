# Platform, GPU & Print Hardware Parity

> **Scope & Environment Note:** Cross-platform installer manifests (`packaging/`), `--control <port>` / `--headless-once` / `--portable-dir` / `--ttf-font` / `--rulers` binary entrypoints (`apps/lumencraft`), `WebWorkspaceHost` local browser workspace shell (`apps/lumencraft-web`), CPU rasterizer & ECMA-234 `.emf` encoder (`lumencraft-render`), multi-flavor clipboard payload builder (`ClipboardBundle` with `pdf_bytes`, `svg`, `emf_bytes`, `html`, `png_bytes`, and locale-aware TSV), subprocess OS pasteboard/print adapters (`write_os_pasteboard`, `read_os_pasteboard`, `submit_os_print_job`), live macOS `/usr/bin/pbcopy` + `/usr/bin/pbpaste` roundtrip (`macos_clipboard_live`, `EXECUTED_LIVE_ROUNDTRIP`), macOS `Info.plist` `plutil -lint` + ad-hoc `codesign --verify --strict --deep` validation (`xtask/src/bundle.rs`), HiDPI `ViewportMetrics` (`1.0x`–`3.0x`) + `UiInputEvent` dispatch (`lumencraft-ui-egui`: `69 passed`), inertial pan/zoom state (`PanZoomInertiaState`), external font discovery (`LUMENCRAFT_FONTS_DIR` / `font_diagnostics`), and physical-scale PDF print spool builder (`PrintJobSpec::spool_pdf`) are implemented and verified headlessly (and live on macOS where noted). Full native OS GPU GUI windowing (`eframe`/`egui`/`wgpu`), live `wasm32` sysroot/`trunk` browser runtime, rich native OS binary vector PDF/EMF clipboard IPC, interactive OS print dialogs, and cross-OS Windows/Linux/FreeBSD/macOS desktop CJK/RTL QA + signed notarized installers remain unchecked (`[ ]`) pending native GUI/CI runner validation ([`ROADMAP.md`](ROADMAP.md#r54-native-binary-os-vector-clipboard-interactive-print-dialogs--live-layout-drag-snap), [`R8.3`](ROADMAP.md#r83-live-os-eframeeguiwgpu-desktop-windowing--interactive-event-loop)–[`R8.5`](ROADMAP.md#r85-cross-os-hardware-cjkrtl-desktop-qa--installersigning-hardening)). See also [`STATUS.md`](STATUS.md).
