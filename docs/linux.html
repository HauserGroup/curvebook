Linux · x86_64 · ARM64

Biostatistics and curve fitting on Linux.
Native, offline, and open source.

CurveBook runs natively on Linux without Wine, a virtual machine, or a cloud account. One portable AppImage contains the desktop app, the curvebook-cli tool, and an MCP server for AI assistants. It opens .pzfx, .prism, .xlsx, and CSV files offline and sends no telemetry.

Quick start

Install and run on Linux

Download the x86_64 or ARM64 AppImage from GitHub Releases. Then make it executable and start it:

chmod +x curvebook-<version>-linux-x86_64.AppImage
./curvebook-<version>-linux-x86_64.AppImage

Without FUSE v2 or for command-line use

Some newer distributions lack FUSE v2 (libfuse2). On those systems, or to run curvebook-cli directly from scripts, extract the AppImage once:

./curvebook-<version>-linux-x86_64.AppImage --appimage-extract
./squashfs-root/usr/bin/curvebook-cli --version

For FUSE problems, see Linux FUSE help. To check your download, see verifying downloads.

Full scientific workbench

What you can do on Linux

  • Open existing lab files: Import tables from .pzfx and .prism files (file-format guide), Excel workbooks, and CSV files. Save your work as a .curvebook file or a Git-friendly .curvebook.d/ folder.
  • Statistics and curve fitting: Run t-tests, nonparametric tests, ANOVA, survival analysis, ROC curves, PCA, and nonlinear regression. Fit built-in models or write your own equations. See the analyses and curve fitting references.
  • Publication figures and layouts: Arrange multi-panel figures at journal column widths, with significance brackets and colorblind-safe palettes. Export vector SVG, PDF, or EMF files, or raster PNG or TIFF images. See graphs and layouts.
  • CLI and AI assistants: Use curvebook-cli to automate batch work, or connect an AI assistant through MCP. Read the beginner's MCP guide.

Packaging scope

Beta Linux packaging notes

  • AppImage only in Beta: Releases include portable x86_64 and ARM64 AppImages for Wayland and X11, with checksums and build attestations. Native .deb, .rpm, and Flatpak packages are not built during Beta.
  • Offline, with no telemetry: CurveBook makes no network calls, collects no analytics, and has no auto-updater. Read the Privacy Policy.
  • Open source: CurveBook is dual-licensed under MIT OR Apache-2.0, and you can build it from source on GitHub.
