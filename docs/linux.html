Biostatistics and curve fitting on Linux.
Native, offline, and open source.

CurveBook runs natively on Linux without Wine, virtual machines, or cloud accounts. Each portable .AppImage bundles the pure-Rust desktop GUI, the headless curvebook-cli runner, and the local stdio MCP server — opening .pzfx, .prism, .xlsx, and CSV/TSV data tables offline with zero telemetry.

Quick start

Install and run on Linux

Download curvebook-<version>-linux-x86_64.AppImage (or aarch64 for ARM Linux) from GitHub Releases, mark it executable, and launch:

chmod +x curvebook-<version>-linux-x86_64.AppImage
./curvebook-<version>-linux-x86_64.AppImage

Without FUSE v2 (libfuse2) or for headless CLI use

If your distribution does not ship FUSE v2 (for example newer Ubuntu releases) or you want to invoke curvebook-cli directly in scripts and MCP clients, extract the AppImage once:

./curvebook-<version>-linux-x86_64.AppImage --appimage-extract
./squashfs-root/usr/bin/curvebook-cli --version

See Troubleshooting: Linux FUSE and Verifying downloads for SHA256SUMS.txt and keyless GitHub Sigstore attestation checks.

Full scientific workbench

What you can do on Linux

  • Open existing lab files: read data tables from .pzfx and .prism files (file-format guide), Excel .xlsx workbooks, and CSV/TSV files, or work natively in .curvebook archives and Git-friendly .curvebook.d/ directories.
  • Biostatistics & nonlinear regression: run t-tests, nonparametric comparisons, ordinary, repeated-measures, and REML mixed-effects ANOVA with multiple-comparison post tests, Kaplan–Meier and Cox proportional hazards survival analysis, contingency and ROC analyses, GLMs, PCA and clustering, power planning, and weighted or robust nonlinear curve fitting (including custom DSL and ODE models). See the analyses reference and curve fitting reference.
  • Publication figures & layouts: compose multi-panel figures on physical millimeter presets with significance brackets, compact letter display, live TeX equations, and colorblind-safe palettes, then export vector SVG, PDF, EMF, and raster PNG / TIFF. See graphs and layouts.
  • Headless CLI & local AI automation (MCP): run reproducible batch pipelines with curvebook-cli or connect local MCP assistants via curvebook-cli mcp --workdir <folder>. See the Beginner's MCP Guide.

Packaging scope

Beta Linux packaging notes

  • AppImage only in Beta: Beta GitHub Releases ship portable x86_64 and aarch64 AppImages tested with Wayland and X11 portals, paired with SHA256SUMS.txt and Sigstore build provenance attestations. Native .deb, .rpm, and Flatpak packages are not part of the Beta download set.
  • Zero telemetry & offline-first: CurveBook makes no outbound network connections, sends no analytics or crash reports, and includes no auto-updater. Read the Privacy Policy.
  • Build from source: CurveBook is dual-licensed under MIT OR Apache-2.0 and builds from source with Rust; see the GitHub repository.
