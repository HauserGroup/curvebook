Quick start

Install and run on Linux

Download the x86_64 or ARM64 AppImage from GitHub Releases. Mark it executable and launch:

chmod +x curvebook-<version>-linux-x86_64.AppImage
./curvebook-<version>-linux-x86_64.AppImage

Without FUSE v2 or for command-line use

On newer distributions without FUSE v2 (libfuse2), or to run curvebook-cli directly in scripts, extract the AppImage once:

./curvebook-<version>-linux-x86_64.AppImage --appimage-extract
./squashfs-root/usr/bin/curvebook-cli --version

Need FUSE troubleshooting or download verification? See Linux FUSE help and verifying downloads.

Full scientific workbench

What you can do on Linux

  • Open existing lab files: Import .pzfx and .prism tables (file-format guide), Excel workbooks, and CSV files. Save natively as a .curvebook file or a Git-friendly .curvebook.d/ folder.
  • Statistics & curve fitting: Run t-tests, nonparametric tests, ANOVA, survival analysis, ROC curves, PCA, and nonlinear regression. Fit built-in models or write your own equations. See the analyses and curve fitting references.
  • Publication figures & layouts: Arrange multi-panel figures to journal column widths with significance brackets and colorblind-safe palettes. Export vector SVG, PDF, or EMF and raster PNG or TIFF. See graphs and layouts.
  • CLI & AI assistants: Automate batch pipelines with curvebook-cli, or connect a local AI assistant via MCP. Read the beginner's MCP guide.

Packaging scope

Beta Linux packaging notes

  • AppImage only in Beta: Releases ship portable x86_64 and ARM64 AppImages for Wayland and X11, with checksums and build attestations. Native .deb, .rpm, and Flatpak packages are not built in Beta.
  • Offline & zero telemetry: CurveBook makes no network calls, collects no analytics, and has no auto-updater. Read the Privacy Policy.
  • Open source: Dual-licensed under MIT OR Apache-2.0 and buildable from source on GitHub.
